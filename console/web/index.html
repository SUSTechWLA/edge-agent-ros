实测标定板尺寸

用尺测量，或核对此板对应版本的加工图。横向为左到右，纵向为上到下。尺寸填写毫米。

现场如何举板和录制
  1. 将车停稳并保持传感器固定。确认板面平整，光线均匀，避免逆光和反光。
  2. 把板放在相机与需要标定的雷达共同视野内，手扶板边，整块板入镜，四个圆孔后方留空。
  3. 举稳板，等工位确认本组已保存。随后向左、右或高低移动并改变俯仰、偏转角度，再次停稳。
  4. 工位自动从传感器录制数据。按当前提示补拍，直到独立验证通过。
