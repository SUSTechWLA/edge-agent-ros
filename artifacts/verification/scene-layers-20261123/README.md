# Jetson 归档的地图查询与热停用验收

本地工作台使用同一 Jetson 归档，分别启动双 MID‑360 占用、D435 纹理表面、场景查询三个 DSH 提供者。录像来自操作工作台的真实浏览器，页面请求实际插件和原版局部规划服务。运行不需要访问机器人。[前端录像](scene-layers.mp4) · [操作回执与章节](acceptance.json) · [运行方式](../../../perception/scene_layers/README.md)

录像长 32.29 秒，已全片解码核验。第 6 秒显示联合查询被拒绝的原因，第 18 秒停用纹理并验证新读取被拒绝，第 22 秒起分别重新计算现场近障和仿真箱体路径。

## 场景查询

| 实测观测 | 归档结果 |
|---|---|
| 双 MID‑360 | `base_foot` 帧，330 个 10 cm 占用体素。两台雷达数据包的主机接收时刻跨度约 122 ms。 |
| RealSense D435 | `camera_color_optical_frame` 帧，基于同一曝光的 RGB-D 与相机内参复建 3,824 个带颜色的三角面。遮挡或无有效深度处留空。 |
| 联合查询 | 两层代表时刻相隔 1,217.418 s，参与采样的总时间跨度约 1,217.540 s，超出 250 ms 查询窗口。归档缺少两次观测间的配准变换。服务返回 `scene.missing_registration` 和 `scene.time_skew`，`scene_ref` 为空。两份单层场景均可独立冻结、查询。 |

正向测试也覆盖两份具有相同空间身份、采集时间和兼容语义的图层，可取得联合场景引用。错误的源摘要、几何与原始传感器不一致、机体坐标同名但所属空间不同，以及超出可证明的质量要求，均有反例。[原始归档清单](../jetson-field-scene-20261123/sensor-evidence/manifest.json) · [核心测试](../../../tests/test_scene_layers_057.py)

随后使用同一组 D435 观测导出独立纹理地图。640 × 480 的彩色 PNG 原样嵌入 GLB，2,766 个参与构面的顶点组成 3,824 个三角面。按三角面在原图中的投影面积计算，覆盖约 39.8%；深度孔洞与遮挡边缘在模型中保留。Khronos 校验器报告零错误、零警告。含现场图像的模型仅在本机保存为 `artifacts/verification/rgbd-texture-20261123/d435-rgb-map.glb`。[导出校验回执](../rgbd-texture-20261123/gltf-validation.json)

浏览器抽查了三角面内部的明亮细节。源图像素 (339, 4) 的红通道为 165，三顶点的红通道最大值为 41。实际绘制时能在面内读出该亮部。切换到深度几何并切回后，观察角度与原纹理画面一致；占用图的像素摘要也保持一致。[浏览器验收回执](../rgbd-texture-20261123/browser.json) · [可复现测试](../../../tests/system/scene_texture_browser.cjs)

## 软件插件停用后重新规划

工作台通过现有 DSH 管理器发布排空修订，等待纹理进程退出，再移除服务。新读取返回 `plugin.service_missing`，旧冻结清单的元数据仍然可以按摘要读取。单独的生命周期测试验证已受理的读取可以完成、旧端点不能受理新读取、纹理损坏时其他插件仍可用、重新启用及同一站点状态目录的启停意图恢复。[生命周期测试](../../../tests/test_scene_layer_runtime.py)

| 传给原 `planning.local_path` 1.1.0 的输入 | 停用前 | 停用后 |
|---|---|---|
| Jetson 归档的实车近障帧 | 保持原位，0 路点。已见车身净距 0.041 m，要求 0.550 m | 新请求仍返回保持原位 |
| Gazebo 归档的中央箱体 | 候选曲线 123 点，观测覆盖 82.6% | 新请求返回相同曲线 |
| Gazebo 归档的空场 | 直行路径 2 点 | 新请求返回相同直行路径 |

三种输入均由独立 HTTP 端到端测试在停用前后配对验证。视频展示现场与中央箱体的前后对照，空场另有测试证据。评估次数由下游 HTTP 服务逐次记录，回执同时固定传感器输入、DSH 绑定和几何摘要。所有规划的 `motion_authorized` 为假。[工作台端到端测试](../../../tests/test_scene_workbench_057.py)

同一工作树还在 Linux/amd64 Docker 中以单 CPU、禁外网、仓库只读且无机器人设备的配置串行运行了 29 项回归。七项地图核心、四项插件生命周期、一项 HTTP 端到端及十七项既有规划和现场数据测试均通过。[容器测试日志](linux-tests.txt)

本阶段验证归档重建、拒绝不兼容图层和软件热停用。Jetson 原生负载、在线融合精度、动态避障和机械臂执行仍待各自验收。前端录像和彩色画面在本地交付。
