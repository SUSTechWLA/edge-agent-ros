# SDD-054 在只读站点创作并复用独立的感知插件

站点提供固定的只读分区统计依赖、允许的数值与分类指令、输入输出协议及独立验收用例。遇到静态感知缺口时，模型从任务含义选择是否创作，输出可独立命名的插件和可执行的受限程序。发布方校验候选，生成 v2 描述符和制品摘要，通过已有 soft 宿主加载，按实际 binding 精确授权。模型及其代码不能改站点策略、运行任意 Python 或访问 ROS 控制端口。

## 验收

1. 首次自然语言请求时工具尚未出现在现场目录。记录原请求、能力缺口、真实模型输出、独立拒绝或通过的用例、增量发布回执、载入前后宿主身份和首次调用。
2. 更改观察区、距离阈值或复核目标后，提交独立的第二次请求。由规划器选择真实插件，记录相同版本和 binding、不同操作及采样时间。无效深度须返回未知，候选近距表面仅用于视区复核。
3. 本机 Docker 服务开机启动，只读 Agent 和所需软件服务使用持久的重启策略。现场验证服务状态、监听端口及能力目录。宿主重启演练需单独安排。
4. 区分实时数据与归档输入。对采样失败、验收失败或拒绝的候选保留真实记录，不向机器发送动作命令。
