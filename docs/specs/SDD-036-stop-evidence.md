# SDD-036 现场停车确认的诊断证据

## 背景与价值

校园第二轮测试出现 `navigation.stop_unconfirmed`。任务回执保留了抑制运动的结果，但值班人员只能看到最后一帧里程计的时间，无法从原事件判断确认窗口里有多少新样本、样本是否仍显示运动、到达间隔是否发生中断。物理结果未知时，重复导航会引入第二次副作用。

## 设计与契约

由持有运动授权的 Gateway 给现有终态事件补充确认窗口统计。`accepted_samples` 是发出制动请求后收到且通过校验的里程计包数。旧包可能延迟到达。用 `quiet_samples`、`quiet_acquisition_ms` 和 `quiet_arrival_ms` 分别读取连续静止样本数、采集跨度和到达跨度。`sample_gaps` 只在后一个有效包到达时才能累计。`last_odom_age_ms` 是最后一个有效包到达后经过的墙钟时间。窗口同时保留最后的线速度模长、偏航角速度绝对值。时间回退、错帧、非有限数和断流均可能导致零有效样本，区分原因需要传感器侧观测。网关沿用原有的制动、300 ms 双时钟确认、3 秒限时及失败后抑制策略。EventBus 和工具回执沿用原 operation/task 链路。

## 验收与证据

| 编号 | 判据 |
|---|---|
| AC-1 | 正常传感器下受阻并完成制动的终态含时间窗及至少三帧符合静止条件的里程计。 |
| AC-2 | 里程计时钟回退导致制动反馈无法确认时，事件可显示采集和到达证据缺口，结果为 UNKNOWN，下一次运动仍被抑制。 |
| AC-3 | 可通过任务关联的归档事件追溯字段。缺少扩展字段的历史任务保留原来的解释。 |

## 迁移与回退

仅替换包含网关的镜像；先排空运行中的运动任务。使用上一版镜像时仍可读取保存的事件。
