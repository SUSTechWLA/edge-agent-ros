# SDD-053 在原感知任务中开发、验证与复用只读数值工具

## 背景与价值

在 SDD-052 的实机系统上，模型能选择已经注册的图像分析工具。遇到需要对其结果做新运算的任务，单靠冻结工具目录仍有能力缺口。用户希望接收一次自然语言任务后，Agent 自己拆分、开发、检验缺失的子工具，并完成本次与后续任务。当前交付范围是单帧静态感知。

## 设计与契约

部署方批准静态输入源、数值语言的运行器和可独立验收的计算契约。模型自主选择现有 Tool 或组合观测与计算，负责生成缺失的数值程序。程序只能对数量受限的有限数列做纯计算，输入来自同一帧的已验证区域统计。安装路径由内容摘要推导。运行器读取已验收制品，对固定契约复核后执行。后续任务读取已安装的同一制品。执行前依然核对 DSH 运行器和观测依赖的冻结绑定。模型无法修改能力策略、物理服务、框架源码和验收用例。

启用部署只读策略的机器人按整项请求判定。明确要求修改机器人框架、底层控制、底盘参数、固件或物理权限时，任务进入 BLOCKED，记录 `planner.system_change_requires_review`。模型也可用 `requires_system_review` 表示其识别出的变更意图。新任务、已保存的规划意图和恢复的待派发步骤使用同一部署限制。读取参数、分析固件升级记录和讨论控制器调优方案可继续通过只读目录规划。实际变更由部署方独立审批、发布。

## 验收与证据

| AC | 预期行为 | 核对方法 |
| --- | --- | --- |
| AC-1 | 同一任务拆成现场采样及缺失运算，作者首次提交真实程序 | 核对原始请求、模型输入与输出、任务 ID 和生成文件 SHA-256 |
| AC-2 | 模型未见的独立用例全部通过才能进入目录 | 复算期望、拒绝错误算术、非法指令、超预算与损坏制品 |
| AC-3 | 原任务执行，第二次不同任务复用同一制品 | 核对两次 operation_id、两次独立采样、发布和 reuse 事件、原图与回执 |
| AC-4 | 越界目标停止在授权边界 | 隔离模拟控制提案和篡改用例，核查无人机、底盘、ROS 执行器调用次数 |

## 迁移与回退

作者功能必须显式启用。旧站点仍使用原有 planner 和只读插件。部署新增 DSH 只读投影、只读求值服务、单独的制品卷与只读验收规格目录。关闭作者入口、撤销运行器绑定后停止新增调用。待在途只读操作结束再排空软件插件，已存程序、冻结计划和历史任务保留以供追溯。

## 变更记录

2026-11-20 基于 SDD-052 的只读 Agent 加入范围受限的缺口补全。验收区分 Agent 模型写出的程序和部署方事先提供的协议、数据算子、独立判据及运行器。

真机任务 `jetson-develop-range-01` 中，作者把区域采集与数值计算混在一起，两份候选均在安装前被拒。将作者输入收窄到分解后的标量运算后，同一句原始请求通过。任务 `jetson-develop-range-02` 在 Jetson 本地推理得到指令 `max min sub`，通过 5 组未发给模型的独立用例。原任务从真实区域深度算出 0.294 米。任务 `jetson-reuse-brightness-01` 更换为上下两区的平均亮度，调用同一制品计算出亮度差 48.417（0–255 标度），没有再次调用作者。[任务与制品摘要](../../artifacts/verification/navigation-plugins/jetson-read-operator.json)

该实现支持部署方提供可验收规格的单帧区域数值任务。新增数学规格应在独立部署策略中给出含义与保留用例。程序仅可使用数值语言的现有指令，通用源代码开发、模型训练与物理控制另需审查。
