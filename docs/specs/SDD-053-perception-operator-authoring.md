# SDD-053 在原感知任务中开发、验证与复用只读数值工具

## 背景与价值

在 SDD-052 的实机系统上，模型能选择已经注册的图像分析工具。遇到需要对其结果做新运算的任务，单靠冻结工具目录仍有能力缺口。用户希望接收一次自然语言任务后，Agent 自己拆分、开发、检验缺失的子工具，并完成本次与后续任务。当前交付范围是单帧静态感知。

## 设计与契约

部署方批准静态输入源、数值语言的运行器和可独立验收的计算契约。模型自主选择现有 Tool 或组合观测与计算，负责生成缺失的数值程序。程序只能对数量受限的有限数列做纯计算，输入来自同一帧的已验证区域统计。安装路径由内容摘要推导。运行器读取已验收制品，对固定契约复核后执行。后续任务读取已安装的同一制品。执行前依然核对 DSH 运行器和观测依赖的冻结绑定。模型无法修改能力策略、物理服务、框架源码和验收用例。

## 验收与证据

| AC | 预期行为 | 核对方法 |
| --- | --- | --- |
| 1 | 同一任务拆成现场采样及缺失运算，作者首次提交真实程序 | 核对原始请求、模型输入与输出、任务 ID 和生成文件 SHA-256 |
| 2 | 模型未见的独立用例全部通过才能进入目录 | 复算期望、拒绝错误算术、非法指令、超预算与损坏制品 |
| 3 | 原任务执行，第二次不同任务复用同一制品 | 核对两次 operation_id、两次独立采样、发布和 reuse 事件、原图与回执 |
| 4 | 越界目标停止在授权边界 | 隔离模拟控制提案和篡改用例，核查无人机、底盘、ROS 执行器调用次数 |

## 迁移与回退

作者功能必须显式启用。旧站点仍使用原有 planner 和只读插件。部署新增 DSH 只读投影、只读求值服务、单独的制品卷与只读验收规格目录。关闭作者入口、撤销运行器绑定后停止新增调用。待在途只读操作结束再排空软件插件，已存程序、冻结计划和历史任务保留以供追溯。
