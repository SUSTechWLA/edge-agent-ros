# SDD-038 无人车工厂标定验收与发布

## 背景与价值

在 `d03f4a5`，板端 preflight 能确认 ROS 源正在产生新数据，sensor.health 能诊断输入退化。出厂工位还需要把安装测量、相机出厂参数和本机实测窗口绑定到同一台车。工厂工程师完成一次工装设置，之后每台车运行同一程序即可取得一份独立的标定报告。探索插件可以按机器人身份和版本读取报告。

## 设计与契约

选用独立配置插件 `calibration.factory`，由工厂入口调用。它独占自己的持久卷，只读工装档案及 ROS 采集适配器的输入。安装、替换和停用不需要改动 ROS 网关或 Agent 内核。摄像头使用注册至彩色光学坐标系的深度和对应内参，MID-360 使用已转换的三维点云，IMU 使用 SI 单位。部署者对机体、实物序列号、工装固定状态和测量记录负责。

| 输入或输出 | 契约 |
|---|---|
| profile v1 | 机体 ID、hardware 或 simulation、底盘帧、三类设备序列号/话题/帧、带工装参考号的父子外参、相机内参。靶点求解可提供独立验证误差；静止 IMU 安装位姿须有安装测量。 |
| capture v1 | 同机体、环境和已声明时间域，固定台架记录号，三路独立多帧的采集和接收时间（ns）。点云有限数/总数，注册深度有效像素、分辨率、色深与内参时间、矩阵，三轴加速度（m/s²）和角速度（rad/s）。 |
| 观测窗口 | 每路至少 5 帧并覆盖 1 秒，共同窗口至少 0.5 秒。校验源内采集时间递增、延迟、间隙、跨源时间邻近、图像时间对齐和静止离散度。记录陀螺静态均值、加速度均值及波动。单姿态静止样本无法求任意外参、加速度计全轴偏置或绝对时钟偏置。 |
| 发布 | `python -m calibration.factory verify --profile P --capture C --state DIR --operation ID`。同一操作与同一输入可幂等重读，冲突输入拒绝。一次 SQLite 事务持久化模块事件、输入归档、回执和通过的版本。失败保留以前的成功版本，也更新最近工厂检查状态；消费者以最近检查是否通过为准。 |
| 读取 | `python -m calibration.factory status --state DIR --robot-id ID --environment hardware`。返回 VERIFIED / NEEDS_CALIBRATION、错误源、版本和运动授权字段（恒 false）。未验证及环境不符禁止进入建图准备阶段。通过只说明该工装与观测的检查结果；进入新场景后重新核验在线设备、定位、制动与探索权限。 |

## 验收与证据

| 编号 | 输入与预期 |
|---|---|
| AC-1 | 已登记三路设备、独立静止观测和有出处的内外参得到稳定版本，静置陀螺偏置均值可与已知输入比较。 |
| AC-2 | 缺失工装测量/设备序列号、单位或坐标系错误、非有限样本、深度空洞、点云不足、运动、重复或异步时戳给出分源原因，保留旧版本并阻断最新检查。 |
| AC-3 | 通过/失败/重试/并发/重启后能按操作 ID 查到原输入和事件。重复成功操作不能恢复已失效的最近状态。硬件查询不能借用仿真记录。 |
| AC-4 | 像素内参须与现场 CameraInfo 相符，四元数及独立拟合误差须满足契约。不自动发布未知外参或动作为零速度的“成功”。 |
| AC-5 | 独立 ROS 2 工位发布点云、IMU、彩色、对齐深度和 CameraInfo。实际采集命令应通过健康流，分别拒绝雷达无数据、缺 CameraInfo、相机信息时间域偏移，恢复后根据新采样重新发布版本。 |

Windows CPython 运行了 [8 组白盒与 CLI 测试](../../tests/test_factory_calibration.py)，覆盖 18 种输入故障、并发重放、发布事务中断和已知机体丢失采样文件。Docker Jazzy 运行了 [DDS 系统测试](../../tests/system/factory_ros_capture.py)。5 次独立进程调用的退出码依次为 0、2、2、2、0，每次再用独立状态命令核验。三个故障的当前版本均为空，历史有效版本保留。恢复后产生新版本，5 个事件均可沿父 ID 回溯。运动授权字段始终为 false。[机器可读运行证据](../evidence/rover-factory-calibration.json)

黑盒使用真实 ROS 2 消息、DDS 和落盘流程。传感器消息及安装参考来自固定测试工装的数据构造器。实机准入还需用指定序列号的 MID-360、RealSense 和 IMU 在真实工位采集，对照有计量依据的安装测量结果，再复核机械固定和时间基准。[工位与参数说明](../../calibration/README.md)

## 迁移与回退

新机使用空状态卷。保留工厂输入文件及卷，用新操作 ID 记录重装和复测。修理或更换传感器后必须核对序列号、重新测量。在原程序退出后可撤下插件；在途提交由数据库事务保证全有或全无。旧快照可用于历史回溯，恢复旧快照后仍需做当前装配的复核。
