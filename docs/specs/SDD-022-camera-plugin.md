# SDD-022 可热装的多路相机观测插件

## 背景与价值

现有地图处理空间位置。为了看清周边目标的颜色、纹理与外观，开发者需要能从多台相机独立预览真实像素，区分等待图像、正常更新、时间异常和断流。为地图或规划器增加解码职责会耦合运行周期与硬件类型。

## 设计与契约

相机页面通过可选视图清单注册在观测台“传感器原始输入”卡片。同一接口也支持地图以外的独立页面。启动回执与公共归档相符时显示，未来设备型号无需在观测台硬编码。

独立进程按目录中的 sources.json 订阅标准 ROS 2 sensor_msgs/Image、CompressedImage 和可选 CameraInfo。每项有 ID、话题、输入类型与时效要求。使用传感器 QoS，按来源限制尺寸、字节数、更新率与内存。多路增删换版以完整路由快照更新。校验成像元数据后向独立只读浏览页面提供最新预览、来源/帧/采样戳、状态和相机标定摘要。超时或回拨撤下失效像素。ROS 时间检验样本时戳，单调时间检查到达新鲜度。公共事件只记状态与版本，不保存图像。Gazebo 仿真中由可选插件插入固定 RGB 相机，桥接实际传感器消息；板端接入已有驱动话题。

## 验收与证据

- AC-1 独立服务能展示有来源的相机输出，切换相机只读取所选 ID。支持相机数据有行填充的 RGB8/BGR8/mono8 与有界 JPEG 预览。
- AC-2 在插件运行中更换、增加、删除相机定义，坏配置保留最后有效订阅并显示原因。图像、标定、前后版本不能串源。
- AC-3 对损坏输入、过大帧、乱序、源时间过旧/未来、时钟回退与断流，状态、可读图像及恢复可核查，其他来源继续工作。
- AC-4 在隔离 ROS / Docker 验证真实 Gazebo 图像及停止/重启。验收区分仿真、合成驱动消息和真实设备。与 Agent、地图、模型插件的生命周期分别控制。

## 迁移与回退

启停独立 compose.camera.yaml，不更改已安装驱动、地图融合、模型路由或机器人执行器。回退时恢复 sources.json 或停止相机预览及其可选模拟输入服务。保留日志卷。
