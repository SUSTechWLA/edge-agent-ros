## 设计与契约

### 扩展点与所有者

| 项目 | 本次设计 |
|---|---|
| 扩展入口 | Tool / Service / 事件消费者 / 观测 / 配置；已有接口和路径，选择理由 |
| Definition | 输入输出 schema、错误语义、版本、时间/大小/并发预算 |
| Provider | 实现目录、插件 ID / 版本、部署进程、资源与权限 |
| Consumer | 所有直接和间接调用者，调用位置、缺失和不兼容时的行为 |
| 状态所有者 | 谁写权威状态，谁只读；存储、保留期、旧数据兼容 |
| 上下文与证据 | 按实际协议传递的 task/trace/operation/request/parent_event ID；来源、裁剪和缺样标识 |
| 宿主变更 | 是否需要改稳定核心；若需要，为什么现有接口不能满足、最小修改和兼容方案 |
