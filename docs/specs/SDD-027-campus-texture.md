# SDD-027 在二维与三维地图中查看带纹理的仿真校园

## 背景与价值

基线 `4308453` 的地图已经共用占据栅格与语义区域。原地图工作台连接小场景，校园总览另有七个相机视角。开发者需要在交互地图里识别教学楼、跑道、林地和车道，并能放大检查本次校园仿真的局部机器人观测。

## 设计与契约

校园世界的米制坐标、静态模型与材质是外观层的来源。离线生成按世界 XY 配准的正射图，记录 frame、边界、尺寸和资产版本。地图插件只读加载本地纹理包。两个渲染器以同一组地理边界采样纹理；三维沿用透视相机，二维支持整校与局部检查。图层可关闭；占据、语义、机器人位姿继续使用校园 ROS 实例。外观图层有清晰来源，不能用颜色补写未知格值或据此下发运动。加载错误或坐标不一致时提供原因，保留原有地图操作。

## 验收与证据

| AC | 场景 | 验收条件 |
|---|---|---|
| AC-1 | 校园仿真在线 | 独立校园地图端口返回 campus 的纹理和当前 ROS 栅格、位姿；原工作台保持可用。 |
| AC-2 | 正射纹理定位 | 场地的非中心控制点可与模型或场地边界核对，包括田径场、林区和校园建筑区域，Y 轴方向正确。 |
| AC-3 | 浏览器二维和三维 | 通过桌面和窄屏实际打开、切换、缩放、开关纹理。像素发生对应变化，可回到整校或机器人附近。地图拾取保持原始来源。 |
| AC-4 | 降级与隔离 | 缺失、损坏、错帧和无纹理部署仍可查看已有观测；验收过程只读，不产生导航任务。 |

## 迁移与回退

通过单位独立的校园地图服务接入已有校园。新资源只挂载到地图工作台，运行时不需要联网下载。关闭外观层立即恢复纯观测视图；停用校园地图服务即可撤下该展示入口。

## 变更记录

2026-11-18，核对原校园资产、实时工作台、地图提供者和 v1.2.0 两种渲染器后登记 AC-1 至 AC-4。

实现使用插件 `map3d` v1.3.0、校园安装服务和渲染器。离线读取 SDF 几何、原模型三角面和 UV 材质，生成一张按米配准的北向正射彩色图和一张对应高度图。发布时校验两张 PNG 的 SHA-256、尺寸，以及校园实例的场景 ID、版本与 ROS 坐标系。三维取样最高表面，窗内、架空层以及完整立面仍需原生三维网格或传感器。首次测试发现只读容器的临时目录禁止执行，生成器改用世界卷内的临时构建目录并在结束后清理。[安装与操作](../../scene/campus_large/README.md)

工作站使用镜像 `edge-agent-ros:campus-map-42c9adb` 连到既有校园并启动固定激光台站。正射图尺寸 2048 × 1493，覆盖约 577 × 421 米；俯视相机与地图选取跑道、草坪、车道、屋顶等七个控制点比较。ROS 栅格、位姿和点云在线，两个工程此前运行的 30 个容器保留原身份。在 1440 和 390 像素宽度下，两种视图均完成纹理开关、地点取景和相机复位，田径场中心读数为 (−103, 72) 米。另一个全新校园完成独立安装、浏览器验收及穿门任务，Gazebo 真值终点误差 6.58 厘米。首次隔离试验在 Gazebo 扩展 SDF 读取超时后退出，增加有时限的只读重试后从空卷重新通过。[验收及来源](../evidence/campus-texture-map.json) · [二维实景](../evidence/console/campus-texture-2d.png) · [三维实景](../evidence/console/campus-texture-3d.png)
