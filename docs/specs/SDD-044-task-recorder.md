# SDD-044 默认关闭的通用任务录制插件

## 背景与价值

原录像依赖专项试验脚本。复盘真机、软件任务或不同仿真时，需要按任务显式开启录制，连接可选数据源，并能判断录像丢了哪些证据。

## 设计与契约

可选 Compose 服务接受开始、追加、查询和结束。用 recording_id 标识一次录制，用 task_id 绑定归属。每条事件保留源时间、接收时间和事件 ID。ROS 和 Gazebo 适配器读取各自数据源，HTTP 调用方也可记录纯软件任务。录像服务器不授予运动权限。SQLite 存储经提交的源事件和媒体，每次结束导出可搬运的时间线，重复结束可恢复导出。UI/视频编码和高频收集彼此独立。记录器重启要公开标明中断；持久化容量与每次请求有限额。

## 验收与证据

- AC-1 默认 Compose 不启动录制。显式启用后，纯软件任务可按 task_id 录制/回查，启停不影响运行中的任务。
- AC-2 重投请求可幂等处理，任务间隔离；重名媒体、状态冲突、未知来源、非法输入和容量上限得到明确反馈。重启保留证据并标记中断，可查询实际来源及缺帧。
- AC-3 同一录制机制承接校园实验的仿真相机、地图、位姿与事件，成片可播放并从源时间追查。现场语义标注与验收世界真值对决策模块隔离。
- AC-4 接入现有 Service 注册和排空逻辑。并发录制可分别收尾，排空后仍可写入原录制与幂等重投，新 ID 被拒；重新启动后显式恢复准入。支持 Linux 与 Windows 开发机操作。
- AC-5 校园工作台使用自己的网络、ROS 域和插件注册卷，显式开启录制应接入该项目实际在用的注册卷，不重启原 Agent、地图或模拟器。
- AC-6 对瞬时结束的任务，即使首次状态已成功，仍须从 Agent 的公开任务分页接口读完该任务保留的工具历史。核对任务、操作、事件与源序号，每条只投影明确列出的身份字段。可单独选录经过已知凭证模式脱敏的用户请求，常规启动默认关闭该来源。

AC-6 的 HTTP 测试用 38 条事件、跨任务全局序号跳号、观察器重入、混入其他任务的事件、不合法的分页与时间、凭据占位值验证行为。Docker 运维验收另在三个并行录制中，令 B 的成功回执携带两页共 33 条历史事件，自动关闭前全部按序收齐。只返回状态的 A 诚实列出缺失的 `agent_trace`。[观察器用例](../../tests/test_recorder_cli.py) · [运维实测](../../artifacts/verification/recorder-ops/run04/results.json)

### 运维入口的黑盒验收

在独立 Docker Compose 项目运行三路同时采集。A 为纯软件任务，B 订阅测试 ROS 相机，C 采集 ROS 状态并省略相机。发布端通过 DDS 真实发送 `sensor_msgs/Image` 与时钟，独立 HTTP 夹具控制各任务状态。实际从 B 导出 112 张 PNG、56 条时钟、2 次 Agent 状态。B 的地图、位姿、速度和总线均由 `missing_sources` 如实列出。此项验收覆盖录制生命周期与数据源连接，校园任务、实物传感器和机器人运动能力各自另行验收。

实测默认配置隐藏录制服务，受管安装发布 `task.record` 后开始采集。容器外部的准入管理请求返回 403。在活动任务上排空会拒绝新的 ID，可幂等重试已有采集，尝试为同一次采集改选相机则返回错误。手工停 A 和 C 后 B 仍在工作，B 收到 Agent 成功回执后自动关闭。归档可独立导出，关闭服务后证据仍在，准入状态跨重启保留；显式重新开放后可以开始下一次录制。Linux 接口经 Windows Git Bash 执行，PowerShell 入口也实际查询了正在采集的任务。[黑盒脚本](../../tests/system/task_recorder_ops.py) · [该次运行摘要](../../artifacts/verification/recorder-ops/run03/results.json) · [归档事务与重启白盒测试](../../tests/test_task_recorder.py)

## 迁移与回退

先结束正在录制的任务，再停止专用服务，保留归档存储。现场原始影像是按需采集的数据，由部署方决定保留期和分发范围。

## 变更记录

2026-11-19，应现场调试需求将一次性录制提升为默认关闭的可选服务。

同日实测，隔离 Docker 可同时录纯软件、ROS、选定相机三种任务，按任务结束并导出；校验重启、幂等、配额、纯软件成片和未知校园八种来源。使用者见[插件手册](../../task_recorder/README.md)，故障全过程见[实测](../testing/unknown-campus.md)。
