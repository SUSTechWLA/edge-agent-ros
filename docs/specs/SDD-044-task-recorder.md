# SDD-044 默认关闭的通用任务录制插件

## 背景与价值

原录像依赖专项试验脚本。复盘真机、软件任务或不同仿真时，需要按任务显式开启录制，连接可选数据源，并能判断录像丢了哪些证据。

## 设计与契约

可选 Compose 服务接受开始、追加、查询和结束。用 recording_id 标识一次录制，用 task_id 绑定归属。每条事件保留源时间、接收时间和事件 ID。ROS 和 Gazebo 适配器读取各自数据源，HTTP 调用方也可记录纯软件任务。录像服务器不授予运动权限。SQLite 存储经提交的源事件和媒体，每次结束导出可搬运的时间线，重复结束可恢复导出。UI/视频编码和高频收集彼此独立。记录器重启要公开标明中断；持久化容量与每次请求有限额。

## 验收与证据

- AC-1 默认 Compose 不启动录制。显式启用后，纯软件任务可按 task_id 录制/回查，启停不影响运行中的任务。
- AC-2 重投请求可幂等处理，任务间隔离；重名媒体、状态冲突、未知来源、非法输入和容量上限得到明确反馈。重启保留证据并标记中断，可查询实际来源及缺帧。
- AC-3 同一录制机制承接校园实验的仿真相机、地图、位姿与事件，成片可播放并从源时间追查。现场语义标注与验收世界真值对决策模块隔离。

## 迁移与回退

先结束正在录制的任务，再停止专用服务，保留归档存储。现场原始影像是按需采集的数据，由部署方决定保留期和分发范围。

## 变更记录

2026-11-19，应现场调试需求将一次性录制提升为默认关闭的可选服务。
