# SDD-046 任务、现场与传感器的同步演示录像

## 背景与价值

SDD-044 的录制器已能将同一任务的图像、地图、位姿、速度指令、事件和接收时间封存为可离线读取的归档。旧版视频在地图旁显示相机画面和最新任务阶段，传感器采样间断、速度指令的变化，以及事件与现场观测的关联，仍需要翻原始时间线。现场演示者需要在同一帧回答三个问题。机器人收到什么任务？哪些观测发生了变化？出现异常时有什么证据可核对？

## 设计与契约

在现有离线渲染入口增加显式选择的 `--layout showcase`。输入沿用 `recording.json`、`media/mission/timeline.jsonl` 和原附件，输出单个 H.264 视频、带章节的 HTML 和 SHA-256 索引。保留既有默认版式、归档格式和录制开关。渲染端读取已经封存的材料，现场设备和 ROS 网络权限归采集端所有。

| 画面 | 数据与解释 |
|---|---|
| 现场和地图 | 播放该时刻已经收到的实际图像和有时间戳的地图，使用记录里的帧坐标系叠加融合位置。展示手册指定的相机来源。 |
| 传感器与指令 | 每路显示来源、字段、单位、最近值、样本年龄和短期趋势。优先显示实测激光最近回波、IMU 角速度和下发线速度。较早的录制可使用融合位姿和地图已知格数。已有外部生产者可以在录制时声明自己的来源，使用展示配置选择其中的数值字段。 |
| 事件与证据 | 展示当时已出现的事件、序号及匹配的原始引用。按父事件 ID 或同一操作/任务段 ID 关联。只有共享时间时，只报告实际时间顺序。章节索引可回查展示用到的原始事件和取样。 |
| 无数据及降级 | 区分录制未选择、已声明但尚未到样、最新字段无效、样本超出展示阈值。视频连续播放期间显示保留样本的年龄；超时区间的趋势断开。读取软件任务也使用同一证据规则。 |
| 时钟 | 默认按接收时间播放并注明“距收到”。按源时钟对齐须每条事件都显式标注相同的时钟域。同名话题和同类传感器不能证明两台设备校过时。混合、缺域或已知回拨的源时钟使用接收时间。渲染器的阈值只解释观察连续性。 |

隔离的 Gazebo 夹具可为 ROS 采集服务指定 `LaserScan` 和 `Imu`。以消息头时间保存 `laser_scan.metrics.nearest_m` 和 `imu.metrics.angular_z_rad_s`，并记录话题、坐标系、消息类型、有效性与诊断原因。雷达值来自有效量程内的实测回波，IMU 值来自实测角速度 Z 分量。两路按本机单调时钟限采，默认 4 Hz，可设为 0.1–10 Hz。每条激光消息最多检查 65,536 束，归档保存摘要。无发布者时在缺失来源中体现。无效消息头时间保留原值和原因，另标 `stamp_origin=receipt`，其接收时钟不可当作传感器源时间。实机通过已授权的独立物理采集者向录制服务提交归一化事实。渲染工作站只需归档的只读副本。

## 验收与证据

- AC-1 同一归档的旧渲染入口继续工作。新布局支持校园与纯软件任务，离线校验媒体摘要、任务归属、封存状态；视频可完整解码，在浏览器点击章节可看到对应状态。
- AC-2 给定乱序时间戳、缺帧、缺字段、非法数值、跨时钟事件和已声明缺失的来源，检测时钟域冲突，按选定轴显示观测年龄，超时不连接趋势线。测试读取帧前后两个时刻，未来数据不会提前出现。
- AC-3 在可复查的章节索引中记录原任务 ID、原事件序号、原样本时间和查询字段。父事件链、同一操作、仅同时发生须可区分。速度指令的数值不可用于声称车辆实际移动。使用可控的归档夹具验证关联和配置边界。
- AC-4 用最终通过回归的 Docker 镜像录制一次陌生校园任务。以封存的事件、地图、世界位姿和模型控制回执核对故障停车、再次取得观测和返航。发布成片需附原始时间线摘要、来源计数、完整解码结果和浏览器跳章验证。若有缺失或未执行，应按实际状态登记。

一次扫描收到所有激光束都为正无穷、且无坏值时，保留该条扫描和时戳，将它显示为“量程内无回波”。首样尚未到达、扫描含非法值、扫描已超时分别保留各自状态。使用保留的扫描和归档序号可以区分环境无回波与传感器断流。

Docker 写入的独立世界位姿以临时文件原子替换 `truth.json`。Windows 主机在替换瞬间可能返回共享访问拒绝，导致试验从未读取到数据。验收读取器应在有限时间内重新打开同一文件；持续无权限或损坏的 JSON 必须报错。停车判定仍需两次不同的真实采样。

## 迁移与回退

使用原渲染命令即可选择旧版式。归档保留原样，两种版式可以分别输出到新的目录。部署现场若需要新传感器采样，由对应数据源的独立部署与授权流程接入；其已有录制可以通过可配置数值字段在离线工作站展示。

## 变更记录

并发压力试验中，Gazebo 的独立关节见证曾在读取正确数值后，由 Python 进程退出时的原生回调清理触发 134。跨形态复验改用 Gazebo 的有界原生订阅读取 IMU 与指定关节或机体位姿，要求两个采样进程都正常退出。原有姿态、时间戳、到点和停止判据继续独立核对。

发布验证增加了两个可区分的负例。最终代码首轮板端验收中，四秒工厂夹具的激光有效时长不足一秒，生产检查返回 `capture.duration`；健康对照应采用现场默认采样时长，另用真实的短采样窗口验证拒绝。ARM64 仿真曾在 console 与 perception 进程存活时尚未开放 HTTP 监听，诊断观测到启动约 20 秒后开始返回 200。板端构建测试分别记录启动就绪耗时和就绪后的 API 契约，读状态及提交被拒两个条件均须通过。现场工位仍需测量原生板卡性能。

2026-11-19，基于 SDD-044 的归档接口增加演示版式，分离任务事件关联、观测时钟与现场运动验收。

开发期故障 `campus-01` 中，任务到达终点，但独立录像少了两张决策地图。两次地图发布距上一次分别为 374 毫秒和 250 毫秒，原录制器的 400 毫秒限采略过了它们。校园验收启用 `--all-map-revisions` 并加深该订阅的队列，逐段保留原始时间戳、地图内容和散列核对。复验 `campus-02` 的 5 次选点全部匹配，225 次世界位姿、184 帧现场图像、143 条激光摘要和 201 条 IMU 摘要独立归档。37 条激光摘要没有有效回波，界面按缺值显示。两个试验原件均保存在本地 `.ci-results/sdd-046/`。
