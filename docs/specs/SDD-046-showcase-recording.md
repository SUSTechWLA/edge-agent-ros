# SDD-046 任务、现场与传感器的同步演示录像

## 背景与价值

SDD-044 的录制器已能将同一任务的图像、地图、位姿、速度指令、事件和接收时间封存为可离线读取的归档。旧版视频在地图旁显示相机画面和最新任务阶段，传感器采样间断、速度指令的变化，以及事件与现场观测的关联，仍需要翻原始时间线。现场演示者需要在同一帧回答三个问题。机器人收到什么任务？哪些观测发生了变化？出现异常时有什么证据可核对？

## 设计与契约

在现有离线渲染入口增加显式选择的 `--layout showcase`。输入沿用 `recording.json`、`media/mission/timeline.jsonl` 和原附件，输出单个 H.264 视频、带章节的 HTML 和 SHA-256 索引。保留既有默认版式、归档格式和录制开关。渲染端读取已经封存的材料，现场设备和 ROS 网络权限归采集端所有。

| 画面 | 数据与解释 |
|---|---|
| 现场和地图 | 播放该时刻已经收到的实际图像和有时间戳的地图，使用记录里的帧坐标系叠加融合位置。展示手册指定的相机来源。 |
| 传感器与指令 | 每路显示来源、字段、单位、最近值、样本间隔和短期趋势。默认区分速度指令、融合位姿和地图已知格数。已有外部生产者可以在录制时声明自己的来源，使用展示配置选择其中的数值字段。 |
| 事件与证据 | 展示当时已出现的事件、序号及匹配的原始引用。按父事件 ID 或同一操作/任务段 ID 关联。只有共享时间时，只报告实际时间顺序。章节索引可回查展示用到的原始事件和取样。 |
| 无数据及降级 | 区分录制未选择、已声明但尚未到样、最新字段无效、样本超出展示阈值。视频连续播放期间显示保留样本的年龄；超时区间的趋势断开。读取软件任务也使用同一证据规则。 |
| 时钟 | 默认按接收时间播放并注明“距收到”；仅在单一来源时钟下按源时钟对齐。混合或已知回拨的源时钟要求改用接收时间。渲染器的阈值只解释观察连续性，不参与控制、验收或异常定级。 |

## 验收与证据

- AC-1 同一归档的旧渲染入口继续工作。新布局支持校园与纯软件任务，离线校验媒体摘要、任务归属、封存状态；视频可完整解码，在浏览器点击章节可看到对应状态。
- AC-2 给定乱序时间戳、缺帧、缺字段、非法数值、跨时钟事件和已声明缺失的来源，检测时钟域冲突，按选定轴显示观测年龄，超时不连接趋势线。测试读取帧前后两个时刻，未来数据不会提前出现。
- AC-3 在可复查的章节索引中记录原任务 ID、原事件序号、原样本时间和查询字段。父事件链、同一操作、仅同时发生须可区分。速度指令的数值不可用于声称车辆实际移动。使用可控的归档夹具验证关联和配置边界。
- AC-4 用最终通过回归的 Docker 镜像录制一次陌生校园任务。以封存的事件、地图、世界位姿和模型控制回执核对故障停车、再次取得观测和返航。发布成片需附原始时间线摘要、来源计数、完整解码结果和浏览器跳章验证。若有缺失或未执行，应按实际状态登记。

## 迁移与回退

使用原渲染命令即可选择旧版式。归档保留原样，两种版式可以分别输出到新的目录。部署现场若需要新传感器采样，由对应数据源的独立部署与授权流程接入；其已有录制可以通过可配置数值字段在离线工作站展示。

## 变更记录

2026-11-19，基于 SDD-044 的归档接口增加演示版式需求，分离任务事件关联、观测时钟与现场运动验收。
