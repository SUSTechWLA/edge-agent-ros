# SDD-043 陌生校园冷启动、初图和返航

## 背景与价值

上次巡检在请求中列出七个坐标，检验了任务恢复与执行精度。第一次进场的车缺少场地地图、语义地点和全局定位，需要从自身观测中选择目标。验收使用已有校园 Gazebo 世界和真值作为独立的实验设备。

## 设计与契约

操作者从 Agent 提交一条没有地名坐标和路点的中文任务。实验提供者只读取 ROS 时钟、融合位姿与在线占据栅格，使用 Core 提交/查询/取消动作。在首次有效位姿处建立返航目标，结合已知自由空间、机体半径和未知边界逐段选点。在局部初图获得至少 100 个新增已知格、至少两次有效前沿到点后保存地图并返航。在途失去有效观测时由任务所有者确认原动作状态，再等新观测重规划。长期无数据或未知运动结果需有界退出。固定地图范围来源于测试任务预算及已有内核的控制边界。

## 验收与证据

- AC-1 首次请求不含坐标，新的任务存储和地图从空状态运行。记录第一次扫描、第一幅地图、选点依据。校园资产、路网、世界位姿仅向仿真或独立见证提供。
- AC-2 延迟初始传感器接入和在途短时感知中断。分别留证等待、原动作回执、恢复所需的新消息以及重规划，检验真实运动和停车。持续故障以边界测试区分。
- AC-3 同一个 Agent 任务有初图实物、返航回执及独立 Gazebo 位姿核验。完整录像能看到同一仿真时钟下的自然语言、地图、运动、失败与恢复。
- AC-4 初图存盘后执行一项独立可验的后续工作。由刚保存的占据图和已到点的真实回执选出一个与当前位置、出发位置都分开的复查站，用最新地图规划短程，停在该处并用更新的地图重新统计附近一米的自由、占据和未知格，再返航。保留原始选择依据、回执、复查数据和位姿时戳。
- AC-5 首段已有可见运动时永久断开融合位姿与地图，保持故障直至 Agent 上报。验证取消的是原 Core 动作、停车回执成立、独立世界位姿与速度指令持续受检、此后无重派、无建图或返航成功。验收须同时留存工具、Agent 和录制的实际终态。若停止回执或见证数据不足，则明确报告未证实，并将安全边界试验判为未通过。

## 迁移与回退

独立测试项目启用限定于仿真的提供者与工装档案。原校园工作台和真机配置保持各自的任务与数据。删除本次独立 Compose 项目即可撤下实验。
