# SDD-052 边缘感知任务的自主规划与控制权限边界

## 背景与价值

现场的盆栽测距此前由中文句式匹配调用 `see_object`。需要让边缘 Agent 面对新的问题时从实际可用的软件能力中选择工具和参数，保留证据，同时控制运动授权。

## 设计与契约

启用自主只读策略的 Agent 将受信站点的绑定与实时目录求交，为模型提供工具名、说明与参数。没有匹配模板的任务也通过同一规划入口。模型返回结构化调用建议，Agent 独立核验准入、参数和绑定，冻结后派发，记录原操作和结果。恢复的旧请求也受部署策略约束。执行层拥有运动权限，感知规划器没有申请、提升或模拟这项权限的工具。模型不可达或目标超出能力时产生可解释的阻塞。未开启该策略的原有部署保留原行为。

`query_frame` 是独立的只读 DSH Tool，它从已发布的同一组彩色、深度和内参中计算问题要求的数值。模型通过有限的查询语言组合数据通道、选区、网格和统计量。解释器对语法、坐标、计算量和数据来源实施约束，每次计算固定到一帧，参考绑定与旧回执保持可追溯。工具不会执行任意 Python、系统命令或用户提供的网络地址。定位、里程计和其他感知 Service 仍可独立使用；发布、排空、撤回和换版沿用 v2 soft 站点与冻结协议。

## 验收与证据

| AC | 输入 | 可独立核对的预期 |
| --- | --- | --- |
| AC-1 | 多种没有注册句式的目标 | 现场模型看到实时可用目录，自行选取不同工具或组合，留下原始模型调用与冻结计划，任务代码不包含这几句话。 |
| AC-2 | 帧查询、无效深度、越界或不可执行表达式 | 只读解释器返回可从原始图像独立复算的区域、样本数、单位和统计结果，拒绝错误程序。 |
| AC-3 | 模型越权、伪造只读声明、撤销绑定、旧计划恢复 | 被拒的控制请求在隔离验收中派发次数为零。真实设备仅运行只读任务。 |
| AC-4 | 现场用户任务 | 从中文 POST、能力过滤、模型返回、冻结与调用、原始传感器数据，到 Agent 终态均可关联。视频标出来源时间与回放停留。 |

## 验证与回退

保留部署前的只读站点、镜像与任务卷。恢复时按 v2 排空顺序撤回新增工具及独占 Service、恢复站点锁和读策略，重启后检查旧任务及冻结的绑定。模型可独立停启，矩阵按感知推理、权限与实机分别验证。
