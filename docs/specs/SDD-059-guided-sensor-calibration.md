# SDD-059 静止机器人的自主外参标定

## 背景与价值

操作者打开工作台即可看到当前装配的标定状态。输入「请帮我标定当前传感器」后，机器人提示如何出示标定板，识别目标后自行采集、求解并核验可观测的外参。操作者移动板，机器人保持静止。

## 设计与契约

| 职责 | 输入和输出 |
|---|---|
| 装配与就绪检查 | 按站点、机体、传感器身份、参考帧和配置版本读取当前结果；未标定或无法确认时给出原因。 |
| 目标识别与采集 | 从绑定的话题读带时间戳的观测，使用已声明的板规格识别目标。检测成功后才记录用于求解的样本；采集记录关联原任务和操作。 |
| 通用感知工具 | 同一只读工具按目标参数和部署目录选择检测实现。标定板和校园标志牌共享观测身份、检测框及检测来源。只有能提供几何测量的实现才附带板特征。普通识别任务可以止于检测结果；录制、激光配对与标定验证有各自入口。 |
| 外参估计 | 从不同位置的板观测估计目标传感器相对参考系的刚体变换，以米和四元数给出父子帧。不具备底盘参考的自由板观测只能约束传感器间外参。 |
| 验证与保存 | 用留出观测检查误差和几何条件，保留结果、输入来源和适用范围。候选结果的生成和应用到运动系统分别授权。 |
| Agent 与工作台 | 每轮模型读取已注册能力、原任务及工具反馈，选择下一次调用并留下决策记录。提供者保存样本与操作状态，校验调用的前提。工作台可读取提示，启动时查询状态不触发采集。 |

## 验收与证据

- AC-1 空状态启动时在用户提交任务前显示未标定；没有观测到板时保持等待。
- AC-2 通过正常 Agent 接口提交一次自然语言任务。仿真用户出示和移动标定板后，系统自动取得真实 Gazebo 传感器观测并持久化标定记录。
- AC-3 不把传感器外参真值作为求解输入，使用留出观测和独立的模拟安装值分别复核。同姿态退化、未配准的传感器、缺少有效观测分别保留原因。
- AC-4 同一任务重查保持操作身份，重启后仍能读取持久化结果。插件停用或不可达时报告不可用。验证记录注明未覆盖的传感器，不能由静止举板推断 IMU 的完整外参。
- AC-5 使用实际运行的模型选择原子工具，记录模型身份、选择及结果。加入重复板姿后，由模型依据反馈决定补采。缺少模型或有效候选动作时停止并说明原因。本阶段不注册标定 workflow 或 skill。
- AC-6 同份真实渲染的 RGB 图像经同一识别接口分别查询标定板与非板目标，返回相应目标与来源。未安装对应实现时给出明确的不可用结果。单独查询普通目标保持采集数量、标定版本和运动状态不变。
- AC-7 从正常入口提交时间标定自然语言任务，Agent 自主选择采集、估计和检查能力。在已确认空间外参的固定工位上，分别按彩色图和每台雷达自己的采集时间提取同一运动靶的观测。求解器只读取这些观测和空间外参。另一个验收程序知道注入的时差，对照估计值及留出误差。时间标定保留每路方向、单位、样本区间、适用范围和空间标定版本。
- AC-8 静止、运动不充分或无法唯一匹配的标靶不产生可用于融合的新时差。时间校正仅供已绑定的传感器及有效窗口使用。超出当前证据可支持的时间误差时，消费者保留独立的雷达观测，语义关联等待新的验证。工位没有运动或修改传感器时钟的执行工具。

- AC-9 四孔板空间标定按站点选择已安装的方法。用户在工作台确认板编号及实测的标记边长、标记中心距、孔中心距和孔径，指标绑定本次标定。没有物理尺度时只给出准备提示。
- AC-10 操作者通过实时 RGB 和各雷达的观测回执摆板。仅在共同视野、时间配对、短时稳定、独立姿态满足要求时增加计数。记录可回看，丢失传感器、孔被遮挡或重复姿态时显示具体原因。
- AC-11 新方法使用与棋盘相同的自然语言任务入口及候选外参、独立留出验证的边界。记录区分实际硬件、上传照片、仿真和合成传感器流。未经实机独立验证的结果不得用作实机装配参数。

## 固定靶标与底盘自主换位

在允许移动的站点，板固定在场地中，相机和雷达随底盘一起换位。通过相同的观测、采集、求解和留出验证接口完成标定。视角评估以各传感器的可见范围、目标当前观测和已采姿态为输入，输出候选观测方向与几何退化原因。标定度量使用传感器各自实际观测到的板要素。名义安装值用于选择视角，求解与验证使用独立观测。

| 能力 | 接口与所有者 |
| --- | --- |
| 视角评估 | 只读软件能力。根据靶标可见性和已采姿态推荐候选位置，附参考帧、来源、观测时间和适用范围。候选位置本身不授予运动权限。 |
| 有界换位 | 独立部署的 DSH physical provider。接收经过现场约束验证的相对姿态请求和操作 ID，由车端仲裁独占受控输入，检查传感器覆盖、时效、碰撞制停与下游停车反馈。人工接管与急停具有更高优先级。 |
| 每次停稳采集 | 当前标定工作台继续使用姿态去重、时间配对及四孔检测。自主换位场景用已确认停稳且属于该次操作的观测窗口。漏孔、失去相机观测、位姿重复时将原因返回给 Agent。 |
| 恢复与发布 | Agent 用回执选择下一次动作。运动结果不确定时按原操作号对账，物理运行时冻结再次换位。发布仍要求同一传感器装配、独立样本和通过留出验证。 |

- AC-12 在独立回放中固定板的世界位姿及传感器安装，以五个不同的平面底盘位姿生成各自观测。三组拟合、两组留出，按独立安装真值核对误差。仅横移导致姿态退化时拒绝样本。
- AC-13 在仿真中从正常自然语言入口完成固定板任务。模型依据最新工具回执决定观察、换位、采样或求解。每个物理步骤有独立动作回执和停稳窗口。退化、遮挡或换位受阻时，收据说明原因并允许保留原操作继续检查。
- AC-14 实车启用前，验证申请方向上整个扫掠范围的障碍制停、数据失联时的独立截止和控制权撤销。缺任一证据时原车端停车机制仍有效，Agent 返回受阻。
- AC-15 工位可为缺少运动能力的复合任务登记只读诊断工具和每任务预算。原始自然语言目标、未满足的能力、目录及本任务已得的回执一起交给端侧模型。模型可选观测或报告受阻，任务账本须保留缺口。只读成功、重复请求、重启与配置撤下均不能把原任务记为标定成功，也不能授权底盘动作。未配置诊断的工位沿用原准入规则。
- AC-16 站点可提供一次共同视野检查。回执区分 RGB 与每路已绑定雷达的观测，并注明数据缺失或不可配对。检查的任务不会接管其他采集会话、增加样本数或发布外参。上层从任务账本验收；工具顺序与取景决策由 Edge Agent 持有。
- AC-17 模型提出的当前动作按原任务和绝对步骤号单独冻结；数据库重启和响应丢失重投原提案，参数改变、前序未结算、撤权或回执绑定不符时阻止新的动作。当前视点的候选引用由观测提供者签发。一次换位后使用新观测，禁止复用旧的相对坐标。
- AC-18 仿真和实车的 Agent 任务入口、目标、动作参数、单位、工具名和完成判据保持一致。底盘接受车体系前进与逆时针转动，验收包括末端朝向与停稳。仿真内的里程计、制动、独立真值和碰撞输入由适配层提供，模型无法调用 Gazebo 设置位姿、世界真值或控制器内部传输。仿真通过仅验证配备这些能力的站点。
- AC-19 在已授权自动换位的工位提交「请帮我标定当前传感器」。工作台显示车头摆板提示，原任务用两个同步观测确认板的位置、朝向、四码、四孔和静止，然后才可申请换位。在此之前独立见证器须观察到底盘静止。旧任务或其他任务的摆板回执不授予本任务运动权限。未部署目标授权的站点继续按原权限执行。
- AC-20 局部可见的标记可为新取景提供有度量依据的位姿。标定采样仍须满足完整靶标、不同姿态与稳定窗口要求。四孔对应跨训练姿态检验唯一性；独立留出姿态和世界安装真值分别验收结果。原前端任务、录制数据、外参版本和到点回执可用同一任务编号查回。
- AC-21 启用目标跟踪的轮式工位只提供全程可见的取景路径。规划检查从起步转向、直行到末端调头的 RGB 投影，使用有尺度的靶标外沿留出边距。支持后向制停的独立 Gazebo 工位可使用受限倒行，让车面向目标拉开距离。候选仍附原观测和终点朝向，运动由已安装的底盘插件授权和验收。
- AC-22 可替换的 RGB 目标提供者在采集时钟、光学帧和目标引用下输出像素框。执行时以实时框和旋转限幅约束跟踪修正。目标出画、识别歧义、提供者拆除或数据过期时，底盘停止并按原操作号对账。重装提供者不会自动重做旧动作。未配置目标跟踪的旧工位仍可读取历史结果并使用原取景方式。
- AC-23 取景读插件在相机观测时间附近关联车体启动局部位姿和周界扫描。向模型提供有原点代次及时间的米制 XYZ、姿态四元数和便于阅读的航向、靶标位置和方向净空。启动局部坐标可因里程计失效重建并产生新代次，旧代次的候选不得驱动车辆。平面底盘锁定高度和滚转俯仰，通用位姿结构保留三维姿态。
- AC-24 多候选优先补齐靶板左、右侧的真实观测基线与 RGB 九宫格标记角点。差速底盘用斜向前进或倒行实现侧向位移。候选在前后方向切换、转向、平移期间须满足完整靶板的 RGB 视野，终点须符合雷达视场，路径须通过本地周界扫描的足迹筛选。周界未知或缺少当前位姿时不提供可执行候选。独立制停和停稳验收继续生效。
- AC-25 用独立 Gazebo 世界轨迹核对固定板两侧的实际采样位置，按原始 RGB 标记角点复核覆盖，再以留出姿态复核外参。平面车在固定直立板工况下仍使用当前相机内参，需更多俯仰、滚转姿态的相机内参估计沿用独立契约。

**移动跟踪边界。** 观测适配器接入现有目标识别提供者，支持替换目标和识别实现。路径规划持有几何投影，执行器消费带时间戳的有限像素量和原候选路径约束，保留已有独立避障、限速和停稳验收。实时观测进程停止时，执行器按失联处理。换版在车体静止、无活动操作时重新冻结物理提供者绑定。仅标定站点启用该配置，当前几何规划验收针对固定目标。

AC-13、AC-19、AC-20 已在本地 Gazebo 工作台验收。车从静止等待摆板开始，按模型选择的视点换位四次，停稳后完成五组观测、求解和留出验证。实车已验证有人监护的直行、原地左转和软件停车，AC-14 的车端权限以及扫掠方向制停仍待实机验收。[独立闭环验收](../../artifacts/verification/fixed-rover-gazebo-20261125/fifth-run/summary.json) · [固定板回放](../evidence/fixed-board-rover-replay-20261125.json) · [实车控制记录](../testing/lingao-chassis-control.md)

## 相机内参和联合验收

- AC-26 内参采集读取未重映射的 RGB 像素，按任务报告九宫格角点落点及缺失区域。工位将板的下一次位置和俯仰、滚转指导返回工作台，操作员只移动板。仅当观测时间新鲜、板稳定且与已收录姿态可区分时接纳。缺少底部和多轴倾角时保持可诊断的未就绪状态。
- AC-27 内参拟合只使用训练组的角点与靶标尺寸，系统已有内参用于评估取景，Gazebo 真值仅进入验收。独立留出姿态用部分角点估计板位姿，再用其余角点检验内参。联合任务用新内参将独立测得的 RGB 板姿和前雷达孔位关联，在未参与任一求解的姿态上检验外参。
- AC-28 Agent 从自然语言自行选择诊断、采集、估计和验证，软件插件不持有运动权限。验证失败保留原归档。发布记录冻结训练集、留出集、方法和源摘要，联合结果只有内外参同时验证通过才完成。Gazebo 候选用于试验结果复核。

采集工位持有操作、原始数据和发布记录。数值提供者只读传入的观测，可独立停止或更换。活动任务冻结首次使用的服务版本，撤下求解器后保留已有样本，替换需要新任务；关闭站点内参配置后仍可读取原外参结果。此 Gazebo 配置用无畸变针孔估计四个内参，镜头与成像类型由部署指定。

## 联合标定的机体换位与人工补角

- AC-29 启用已验收的换位站点后，联合标定工具复用任务内的首次摆板验收。安全取景提供者按最新相机、位姿、周界、已采样角点及欠缺项返回可达候选与预测收益。Agent 可独立选择换位和采集，运动结果须经既有物理所有者及独立停稳验证；采集时间必须晚于停稳证据。
- AC-30 当前机体的候选无法补足有效覆盖或倾角时，工位可开放带原因的人工补角工具。证据须来自同一任务、当前换位和当前采样集合；未知路径、未确认停车、允许动作内仍有可补齐的候选均不得触发倾板。补角后继续复用原任务的采样及求解能力。求解器和覆盖检查不依赖底盘类型，后续取景提供者可由经独立验收的三维运动插件提供完整位姿候选和可达证据。
- AC-31 用 Gazebo 工位从自然语言提交开始录像。见证记录首次摆板、人工补角前实际底盘换位、物理停稳回执、缺角证据及人工补拍；内外参共用独立留出验证。保留世界坐标、版本和样本摘要，软插件换版前排空工作，卸载换位站点后原有静态取样路径仍可用。

反馈策略可以声明只接受显式肯定回执，并在物理动作后丢弃当前位置相关的旧回执。取景服务返回缺项、已筛选姿态数、预计可补欠缺的姿态数和坐标时间。轮式实现枚举平面位姿。未来的提供者可以筛选三维位姿并给出相同的覆盖预测；执行和独立停稳仍由对应的物理插件负责。单调时钟用于运动回执的时效，采集使用独立见证记录的同域传感器时间，二者分别校验。

当当前靶板姿态的共同视野有利于雷达配对时，工位可先冻结配对拟合与留出的必要样本。留出标签在采集时写入，之后始终排除在求解输入之外。仅有 RGB 的倾角训练样本也可用于内参拟合，外参求解只消费经测量确认的配对拟合样本。若单条安全路径还达不到共同视野，取景插件可以给出逐段接近共同视野的可达候选，仍需停稳并实测确认。

- AC-32 联合取景在净空、全路径 RGB 可见性和共同取景筛选之后比较候选的内参增益。计算投影雅可比并消去每帧可自由调整的六维板位姿，使用训练组累计信息评价候选带来的增量。图像分区和双轴角度仍保留为可解释的采样约束。预留组只参与去重和最终验证。相近像素位置但具有明显不同板面方向的有效样本可为内参增加约束。依据为 Zhang 的平面标定、AprilCal 的下一视点建议、Rojtberg 等的内参不确定度选姿态，以及 FAST-Calib 的停稳多视图配对采集。[Zhang](https://www.microsoft.com/en-us/research/project/a-flexible-new-technique-for-camera-calibration-2/publications/) · [AprilCal](https://april.eecs.umich.edu/media/pdfs/richardson2013iros.pdf) · [选姿态论文](https://arxiv.org/abs/1907.04096) · [FAST-Calib](https://github.com/hku-mars/FAST-Calib)
- AC-33 四孔板联合求解允许站点配置 RGB 重投影与配对四孔三维误差的共同优化。只用拟合样本，同时估计内参、固定的雷达到相机变换及每帧板姿；CameraInfo 和仿真安装真值均不提供拟合监督。发布前继续使用既有独立留出质量门槛，Gazebo 安装真值用于外部验收。[联合标定参考](https://pjlab-adg.github.io/assets/pdf/yan2023joint.pdf)

## 迁移与回退
