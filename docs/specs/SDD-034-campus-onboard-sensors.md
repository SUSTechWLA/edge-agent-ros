# SDD-034 四种校园机器人搭载传感器和场测

## 背景与价值

在 `864bcdb` 校园的原生世界中，轮式车提供水平扫描和 IMU，其余三种机体提供 IMU 与动作反馈。地图台站与原生场地相机固定在环境中，机器人移动时不能代替本体视觉、机载测距或车轮编码器。上机前需要能重跑的车体观测基线，并能从任务记录定位一次测量发生的时间、坐标系和工况。

## 设计与契约

扩展校园场景生成器及其只读 ROS 桥。测量由 Gazebo 传感器或关节状态发布器产生。车装前向 RGB-D 和左右车轴编码器，沿用原有 IMU 与 2D 雷达；Go1 装多线 3D 雷达；G1 装头部 RGB-D；Crazyflie 装轻量前向相机和向下测距。后三种均沿用各自 IMU，腿式平台沿用原有关节反馈。在机体坐标中声明米和弧度的安装外参。摄像头图像标示光学坐标轴，色深和内参保留原始仿真时间。用读数、位姿或独立动作回执验证因果关系。仿真参数用于本机 CPU 可重复验证，具体设备的标定和误差分布需要真机补测。

## 验收与证据

| 编号 | 操作与通过条件 |
|---|---|
| AC-1 | 四种机体可按名字从公开 ROS 话题取得多帧新测量。核对来源、类型、安装部件、尺寸、帧、时间单调和有效载荷；表明开阔区域或超量程时的无效深度。 |
| AC-2 | 从工作台发起穿门、起降、关节动作和一次不支持动作。车开动时实测两个轮速非零，终点停稳。无人机升降时向下距离跟随高度变化。以任务 ID、时间戳和读数留档。 |
| AC-3 | RGB-D 色深可按原始时间与标定关联；多线雷达含有限 XYZ 样本；相机画面和 IMU 来自各自机体。可复用原生话题接口订阅，传感器断流应在验收中被识别。 |
| AC-4 | 单独的校园资产变更具有新场景版本，旧地图、旧任务可按旧版本复盘。校园传感器不获得执行器的写权限。实机部署另按 SDD-032 核对驱动、时钟与外参。 |
| AC-5 | 可为运行中的校园单独启动两个只读页面。彩色相机页能查看轮式车、Crazyflie、G1 的不同光学帧；Go1 基线配备 3D 雷达。RGB-D 页能查看车载同步帧、以像素读取深度和识别超量程。验证前后 Gazebo 容器与启动时间相同。 |

## 迁移与回退

通过受控 `run.py reload --image <镜像>` 排空校园动作并更新世界，然后用同一镜像重装校园地图。Gazebo 中的物理传感器随世界装载，ROS 观测端可独立订阅和退出。使用上一版校园镜像和与它配套的场景源码可重建历史工况。
