# SDD-060 给端侧模型的空间查询

## 背景与价值

固定板标定时，模型需要知道靶标在哪里、哪台传感器看到了它，以及下一次观测缺什么。校园导航时，模型需要区分同名的两个门、门属于哪栋楼、哪个入口适合当前机体。两项任务都需要能追溯到传感器或已发布地图的空间事实。向小模型发送整幅点云或由模型记住一段地图描述，都会丢失查询所需的坐标和版本约束。

## 设计与契约

| 层 | 所有者及表示 | 用途 |
| --- | --- | --- |
| 度量地图 | SLAM、定位与地图提供者持有坐标图、占用体素、距离场或网格，以及独立的颜色/纹理层。空闲、占用、未知分别表示。动态障碍另附跟踪时间有效期。 | 轮式车检查整个足迹和原地转向的扫掠范围。飞行器检查三维走廊。机械臂可按对象引用请求局部高分辨率表面、法向和不确定度。 |
| 语义实体 | 感知提供者从 RGB 实例掩码、标记或文字获得候选，用配对深度、PnP 或配准点云度量位置和范围。用对应采集时刻的定位和传感器外参变换至地图坐标。 | 同类别可以有多个实例。关联用三维重叠、位置不确定度、标签与跨视角一致性。遮挡或重定位有歧义时保留多候选。配准缺失时保留传感器局部观测。 |
| 地点与关系 | 地图所有者保存实体、地点、区域、入口及其有来源的关系。确认与人工修订分别留版本。 | 观测到一扇门能支持“门位于这一区域”。“这台车现在可通过门”还需要匹配机型、足迹、净空和最新障碍。 |
| 模型查询 | 模型取得带类型和引用的局部子图，可按目标、地图版本和任务范围查询。小模型看到少量对象、节点关系、单位、观测时间、缺项及精度。 | 导航、抓取、VLN 和端到端策略可消费同一实体引用，各自通过插件读取对应分辨率的几何。底层规划与执行校验继续使用数值地图。 |

**首版接口。** 工位的共同视野工具返回单帧局部子图，四孔板有光学帧内的三维中心、平面法向和证据引用。单帧对象 ID 仅在这个观测快照内有效。雷达观测成功只建立可见关系，不能据此推断相机到雷达的外参。校园地图的 `semantic.scene_query` 接受地图 ID、不可变 revision、可选名称或实例 ID 和数量上限。地图中只有二维锚点的对象保留二维表示。相同地点名返回全部匹配及截断计数，调用方可以用实体 ID 消歧。地图仓校验工件完整性后再投影。

模型反馈规划只将站点登记的提供者返回的有界子图送入上下文。schema 限制节点类型、边类型和字段大小，外部文字作为数据。控制权、可达性和停车证明由物理运行时独立检查。历史地图查询和单帧观测都附带版本或时间；执行前要重新读取当前局部障碍。

**标定实例。** 模型可查询相机与前雷达各自的可见性，按观测版本请求多种候选视点，然后选择其中之一。视点的光学帧、相机在车体上的安装变换和小车的目标朝向需要可追溯。局部路径的起点与目标含 `x_m, y_m, yaw_rad`。支持原地掉头的轮式车可使用转向、直行、终端对准；拥挤场景可替换局部规划器。停稳后重新观测、按原操作号录制。拟合与留出验证由几何插件完成。输入相机已有内参与拟合得到的新内参分别登记。模型按每轮回执选工具，顺序和拍摄点数取决于观测、方法与权限。

**启动局部位姿。** 主体位姿以启动定位代次为原点，X 指向启动时的车头，Y 向左，Z 向上。坐标值以米记录，姿态同时带四元数和阅读用航向。重定位或数据时钟跳变后由定位提供者签发新代次。标定板仍有自己的光学帧观测，通过与相机时刻配对的车位姿和安装参数获得局部位置估计。模型的同一条查询可读到机器人、目标、四个方向的最近观测距离以及少量候选摘要。候选摘要标明预计终点、朝向、参考板的左侧或右侧、RGB 覆盖增量和足迹余量。模型选取候选引用，数值检查和独立停车权由物理运行时持有。地面底盘执行平面约束，无人机可在相同的 XYZ 和姿态结构下配置三维规划与执行提供者。

**后续接口。** 全局三维实例融合、持续更新的空间关系、地图回环后重投影、动态实体过期、手工纠错及机械臂精细子图各由独立提供者实现。写入新地图修订时保留父版本、原观测、冲突和人工修订者；地图切换后旧路径与视点必须重算。小模型按需请求某个对象的局部图像或几何证据，稠密地图保存在端侧。多视图实例聚合可以参考 [ConceptGraphs](https://concept-graphs.github.io/)，场所与房间层级可以参考 [Hydra](https://github.com/MIT-SPARK/Hydra)。

## 验收与证据

- AC-1 未配准的光学帧不能产生地图位置。一次雷达漏检记录为未知或该帧未检出，禁止从单帧漏检推导空间空闲。
- AC-2 查询明确绑定已发布的地图修订和坐标系，保留二维锚点、同名多实例和截断计数。地图工件损坏时拒绝查询。
- AC-3 模型请求含原任务及经验证的小子图，原始图像、点数组和提供者的任意字段不进入投影。缺版本、引用悬空、数据非有限或超限时不使用该子图。
- AC-4 取景查询按图像时间绑定启动原点代次和观察的周界，模型只接收有界的数值与语义摘要。位姿或周界超时则本轮不产生可执行候选，运动前核对原点代次。

## 迁移与回退

已有地图文件继续由地图仓读取。撤下语义查询服务或移除工位的模型投影配置，旧地图、局部规划和已归档任务仍能按其原有接口读取。存档使用当时的快照身份，新的实现按独立版本注册。
