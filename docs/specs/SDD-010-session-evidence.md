# SDD-010 可读任务会话与按需证据查询插件

## 背景与价值

SDD-009 提供了任务目录和事件回放，但读者仍需在工具请求、轮询回执和内部编号中寻找结论。通用 LLM 同样会把上下文预算花在重复事实上。本次交付让人和模型先读同一份短会话，得到用户目标、执行过程、结果、问题线索及引用，再按需要取得详细证据。

实际案例是巡检路径受阻。同一原因先后出现在网关制动、动作结果、工具错误和 Agent 阻塞中。初步阅读应能理解“前方净空不足，机器人制动并确认停稳，巡检受阻”，进一步检查时才读取激光距离、操作编号或原始回执。

## 设计与契约

### Session 的身份与内容

一次自然语言任务构成一个可读任务会话，身份为 task_id，关联工作通过 trace_id 和显式父任务连接。Console 进程的 session_id 仍表示该进程的一次启动周期。会话内容从权威任务账本和公开事件投影生成，JSON 与 Markdown 共用内容和证据引用。每条事实有来源或明确的缺失说明，不生成未记录的模型内心推理。

`GET /api/session?task_id=<id>` 返回用户请求、任务当前状态、简短进展、诊断、后续工作、证据覆盖范围及查询建议；`format=markdown` 返回人和 LLM 都能读的文本。任务目录复用现有稳定分页。有限展示保留总量、截止序号和被折叠数量，未知插件异常仍能进入摘要。

前端默认进入「任务会话」。点击任务先阅读中文叙述和关键结果，通过证据引用打开详细记录或回放。后台轮询不会强制展开原始数据。旧的运行复盘地址继续可达。当前实测状态、任务终态、步骤最后入账状态有各自的标注。

### 证据插件与 EventBus

目前各模块把事实写入自己的持久账本，Console 导入公开归档，消费者通过 HTTP 按游标续读。新 `evidence/` 插件经该 HTTP 契约读取信息，可以独立启动、停止和卸载。提供者仅保存自己的查询审计事件，通过 ModuleJournal 回到 EventBus。

提供三项 read 能力，分别读取简短会话、发现可查询的字段、在指定任务的公开事件上查询细节。AI 可编写 SELECT 查询，查询只作用于通过公共接口取得的有界内存表。工具不接受数据库路径；结果包含归档身份、加载范围、继续读取游标、截断信息和引用，以便识别证据覆盖不足。查询的输入、完成或失败有审计 ID、调用 trace 与稳定诊断码。

| 能力 | 输入 | 输出与用途 |
|---|---|---|
| read_session | task_id | 与页面相同的简短 Markdown，便于首次定位 |
| evidence_schema | 无 | 公开事件表字段、SQL 范围、限制和查询例子 |
| query_evidence | task_id、sql、after_seq、limit | 行列与引用、覆盖范围、截断/续页说明，按需查看具体调用和测量 |

提供者按固定配置连接 Console，设置读取、运行时间、行数、文本大小与并发上限。SQL 限单条读取，禁用写入、外部库挂载和扩展加载。执行结果只证明本次已加载范围中的事实。大任务需要按返回游标续读，无法将部分范围的计数宣称为整个任务总量。通用模型可经这些工具进行多轮查询；当前 Agent 的已生成步骤计划仍由原任务控制器执行。

### 扩展与接入

复用既有插件清单、提供者回执、参数校验、ModuleJournal 与 Console 读取协议。新工具可以热挂载到能力目录。Docker 仿真和 Linux 硬件部署使用相同服务，分别通过 Compose DNS 与本机地址连接。首版会话叙述使用有证据的规则投影，以便断网或没有模型时继续复盘。领域插件通过既有稳定 code、detail 和 data 提供可解释事实。

## 验收与证据

| 编号 | 输入与测试 | 预期 |
|---|---|---|
| AC-1 | 成功、阻塞、重试、待恢复、用户取消、缺少归档与未知插件事件 | 短会话正确表达目标和实际终态，结论能定位到事实，周期采样和重复轮询默认不挤占阅读区。 |
| AC-2 | 一项任务上百次调用、同因重复、先失败后成功、同 trace 多任务 | 保留有意义的阶段和结果，说明覆盖与折叠；不以历史错误覆盖后来成功，不以补录顺序猜测因果。 |
| AC-3 | 证据插件查制动距离、工具错误和前因 | 结果来自所选任务公开归档，关键数值与原事件一致；查询有可追溯审计。 |
| AC-4 | 非法/写SQL、递归/超时、巨大字段、空范围、超过加载范围、上游断连、归档换代 | 有界结束和明确诊断，标注部分证据；任务与原始归档无写入，查询错误可被后续查询纠正。 |
| AC-5 | 热加载清单、自然语言“复盘任务 <id>”、真实模型编写查询 | 实际调用插件并取得相同摘要与证据；卸载后目录撤销，复盘网页与机器人业务仍可读取。 |
| AC-6 | 桌面、手机、旧地址、服务/归档中断、任务切换、详情/Markdown导出 | 默认首屏可找到任务会话，按需展开证据，旧响应不覆盖新任务；完成一次中文阅读定位。 |
| AC-7 | 独立 Docker/Gazebo 验收及日常升级 | 记录前后任务身份、终态及归档身份；只更新涉及的服务，清理独立测试容器，保留测试报告和可复跑命令。 |

## 迁移与回退

沿用既有任务与公开事件存储，无需搬运生产者数据库。插件清单可撤回，Console 与插件可分别回退到已验证镜像。部署者保留观测历史卷和插件查询审计卷。缓存或投影不足时回到原始证据接口继续读取。
