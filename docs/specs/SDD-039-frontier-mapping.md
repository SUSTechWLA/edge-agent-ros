# SDD-039 无人车的已知自由空间探索与初始地图交付

## 背景与价值

基线 `d03f4a5` 的感知节点已经把配准过的激光束和位姿累积到固定尺寸的二维占据栅格。新场地没有教学楼、庭院等具名目的地。机器人需要从自己的测量中选择下一个观察位置，使用现有导航执行者，最后交付能复查的地图。

## 设计与契约

**边界。** `exploration/frontier.py` 属于可替换的探索策略。调用者传入同一坐标系中的占据栅格、车体位置、允许探索的矩形范围（米）、包络半径、单段距离上限和已到达的目标。策略只返回一段可达的短直线目标及选点依据。栅格沿用 ROS 行主序，原点为左下角的位置与偏航。只有值为零的单元可通行。负一表示未知，正值需要保守绕行。边界和未知周围保留车体包络。缺图、定位不可信、传感器断流等由输入适配器挡住。来自传感器的空旷、无返回扫描须遵守建图提供者的数据规则。

**循环。** 调用者先验证标定与传感器，再读取当前图和位姿，在已知自由区搜索靠近可见未知区的观测点。按可达路径的第一个转角或单步预算截断。导航提供者负责独占运动、避障、取消和停稳回执；执行成功并获得新观测才能决定下一步。已到达目标、重复无进展、任务时限/步数、移动结果不明及传感器异常均须保留原因。地图范围外不会计作已探索；前沿耗尽但范围内仍有未知时返回部分地图。二维覆盖不证明玻璃、台阶、悬空障碍和室外地形的三维可通行性。

**交付。** `exploration/map_artifact.py` 写出 ROS 地图 PGM/YAML、保留原始格值的 JSON、带坐标系/分辨率/来源/覆盖状态的清单和文件 SHA-256。按操作目录原子发布，重放不可改写不同观测。职责分离使后续 MID-360 激光惯导或视觉 SLAM 可以在相同地图与位姿契约下替换当前基于里程计的制图来源；定位质量门槛、地面分离、动态障碍处理由实际提供者补足。

**选点原理。** 自由格和未知格相邻的边界称为前沿。先从前沿沿自由区向内寻找能容下车身的观测站，再从当前车位按四邻域做广度优先搜索。未知格、正占据值、网格边缘均按车身半径保守膨胀，搜索不会跨未知间隙。候选站按附近未知格数与路径成本评分，平分时有固定次序。附近未知格数是信息增益的近似值，真正的增益须用到达后的新地图核验。给导航的只是一段直线；行驶期间的变障仍需要运动适配器的实时处置。覆盖率分母为中心位于指定矩形内的格数。请求范围超出地图时拒绝裁剪，以免误报覆盖。

## 验收与证据

| AC | 判据 |
|---|---|
| AC-1 | 同一未知场景和预算可重复选出同一目标。目标、全部路径和车体包络位于已知自由区与配置范围内。占据阻隔、窄门和未知隔断不穿越。 |
| AC-2 | 无可用位姿/地图返回明确错误。范围内无未知时完成；剩余未知不可达、重复选点或预算不足时不能宣称区域全覆盖。 |
| AC-3 | 控制侧从新观测连续调用策略，可推进一个初始未知的区域并保留部分或完整地图。移动超时、传感器断流或停止无法确认时不重复执行。 |
| AC-4 | 地图分辨率、原点偏航、格值、PGM 行方向及哈希可独立读取核验。并发/重放不会覆盖历史地图。 |
| AC-5 | 运动适配器可声明有效首段的最小位移。即使最高分前沿的路径在到点容差内就需要转弯，策略也应继续搜索其他满足最小位移、最大步长和包络约束的路径。无法形成有效首段时，返回原因并停止派发。 |

## 迁移与回退

作为新策略接入标定与导航适配层。仅探索过程创建新的地图目录。卸载前由任务所有者排空并确认停稳。保留原标定版本、操作 ID 与地图目录即可离线复盘。已有感知地图和具名导航任务继续使用各自接口。

Gazebo 首轮暴露了一个控制契约问题。某条高分路径的首个拐点仅距 5.23 cm，Gateway 的 5.5 cm 到点容差允许机器人立即报告成功。策略现接受适配器提供的 `min_step`，沿各安全方向展开首段，达到最小位移后才允许拐弯。默认值 0 延续原有调用。新增双走廊测试验证选较低分但可实际推进的前沿，并验证封路后拒绝派发。Windows 与断网只读容器的 `python tests/test_exploration_frontier.py -v` 均通过全部七项。实车需按实测控制容差与里程计噪声设定最小位移。
