# SDD-029 一座连通的校园机器人试验场

## 背景与价值

上一版的测绘楼群、低矮的 NCS 区、教学楼、运动场与树林分别可辨认，但全校看起来像几块独立的模型。测试人员需要一条可以按顺序检验穿门、开阔区定位、过街、遮挡和沿路感知的连续路线。保留能对应实验问题的场所，校园内部统一米制、路网和地表。

## 设计与契约

以代尔夫特测绘区为主体，教学及体育训练区纳入同一规划；入口广场、运动场入口、树下步道、林间小路和测绘区真实道路应有可辨认的连接。优先删去重复布景和缺乏测试用途的孤立模型。场地几何、碰撞、Gazebo 相机和二维/三维地图共用同一个世界。导航授权由原任务内核管理。

## 验收与证据

| 编号 | 行为及通过条件 |
|---|---|
| AC-1 | 整体取景可以同时看清训练设施、道路与周边楼群。无大块无用途的独立试验分区。说明移除了什么以及原因。 |
| AC-2 | 至少一条与真实街网相接的连续路线连接多个测试环境。核对米制接点、间隙及路面的可见性，检查路线与建筑、树干的关系。 |
| AC-3 | 教学楼穿门、运动场细线、树木遮挡、街面和开阔环境各有实际用途与检查方法。分别标出机器人实跑、几何核查与尚未验证的路段。 |
| AC-4 | 独立 Docker / Gazebo 实例能启动，ROS 时间与位置可用。现场打开全校总览和局部书签，检查新的原生画面与网页。 |

## 迁移与回退

仅更改校园场景、地图取景及其安装和验证。用新场景身份使旧版图片、模型和路线失效；保留独立小场景和历史任务账本。用上一分支和镜像可复现实验前的布局。

## 变更记录

2026-11-18，根据全校画面的反馈登记 AC-1 至 AC-4。在改动前，测绘区从训练区以东约四百米才开始，其间的 NCS 资产以地面及室内家具为主。

同日实施。以 TU Delft X 体育园及周边的 545 × 1,170 m 实测地块为底图，保留 187 个完整建筑对象，排除 46 个跨越边界余量的对象。训练楼与体育设施共用一张正射影像，原来孤立的 NCS 场景从活动校园移除。默认地图具备竖幅纹理尺寸预算，校园、操场和广场取景覆盖桌面与手机。

路线从教学楼门外起，依次经过广场、运动场、草地、林带，接入 Mekelweg。二维、三维及原生相机总览均提供路线叠加。数据契约包含 `frame`、`scene_revision`、有序路点和长度，跨版本或脱离 Gazebo 路面的标注不显示。实体路线通过运行中世界和原始荷兰人行道数据核查。ROS 实跑覆盖同会话的门厅往返，三处测站以原车的带时间戳激光核实。日后全线自主导航另行记录实际轨迹和恢复表现。[复测方法与截图](../testing/campus-robot-view.md) · [验收摘要](../evidence/unified-campus.json)
