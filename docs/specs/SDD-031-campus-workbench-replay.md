# SDD-031 从校园地图回到可读任务记录

## 背景与价值

2026-11-18，开发者从 8773 的校园地图找不到事件回溯。该页面由地图插件提供，页头只有“感知工作台”。8766 的工作台仍有任务目录、运行复盘和事件归档。读取一条已完成的穿门任务时，`GET /api/session?task_id=…` 实际返回 HTTP 503 和 `session.service_missing`。日常校园的 Compose 项目没有运行会话提供者，独立的校园插件卷中也缺少服务定义。用户因此无法从地图找到原任务或阅读执行摘要。

## 设计与契约

地图提供三个只读入口，沿用工作台的 `#sessions`、`#review`、`#events`。目的主机沿用当前浏览器主机，端口取自该部署的 Console 公开端口。页面在取得 ROS 数据前即可提供导航。Console 继续持有公开归档，Session 仍由独立的 `session.read` 服务投影。校园启动过程在本项目的卷内初始化默认提供者。可在运行中的校园单独补装和启动，无需重建世界或停止任务。已有替代提供者或排空中的绑定继续由部署方管理。

校园任务视图从现有 Console API 读取任务、步骤、事件和 ROS 来源状态。地图入口由校园部署提供，按任务语义、机体局部观测、校园二维正射与三维场景展示。静态 Gazebo 取景用于认路。任务路线只在观测与语义的参考系可核对时与实时位置展示。开发详情保留任务与操作引用、时刻、新鲜度和坐标系。已有任务台处理提交和授权，校园任务视图只读取台账。未连接观测时仍可阅读地图和旧收据，过期位姿从当前状态中撤下。

任务地图取执行前发布的 `scene.route_planned` 或已核验收据，验证任务、地图版本、坐标系和摘要。普通校园测试步道保留在独立场地地图，任务视图绘制当前路线。局部建议由可装卸的 `planning.local_preview` 读取当前任务航点与新鲜局部栅格，比对坐标系和观测时间后按实际轮式外廓留余量。它发布只读几何建议，控制网关仍负责实际运动。地图消费方接受二维或三维路径，三维保留高度，平面栅格仍为地面规划输入；三维点云覆盖仅表示已观测回波。使用三维占用与三维动力学的策略需要独立提供者和验收。

## 验收与证据

| 编号 | 验收方式与判据 |
|---|---|
| AC-1 | 从地图的桌面和窄屏视口分别访问同一项目的会话、复盘和事件页。自定义端口部署也能访问正确目标。 |
| AC-2 | 在校园首次启动或单独补装后，按历史任务 ID 获取会话，验证目标文本、结果和事件引用，重复补装保留绑定。 |
| AC-3 | 提供者离线时，可读会话给出错误并保留原始归档入口，恢复后同一任务可再次读取。观察期间运动服务、世界和已有任务证据保持可核对。 |
| AC-4 | 注册目录有可替换或排空中的提供者时，默认初始化保留其设置。新地图保持独立，仿真和硬件部署分别使用各自的 Console 地址。 |
| AC-5 | 在独立校园 Compose 上，以教学楼门厅到门外的任务核对 Agent 步骤与独立真值。浏览器通过同一视图显示任务、实时状态、语义路线、机体局部观测以及独立校园二维、三维和静态取景。用窄屏、替代端口和失去实时观测复测。 |
| AC-6 | 同一任务在执行中显示已发布的全局路线和同一航点的局部建议。切换航点、停止、过期或切换任务后旧建议撤下。任务地图隐藏测试步道，长线局部视野根据活动航点截取，三维提供者的路径保持 XYZ。 |

## 迁移与回退

地图链接可随地图镜像回退。根据需要在校园执行已有的 Session 卸载操作。测试记录放在 `artifacts/verification/`，部署与排障入口写入校园运行手册。
