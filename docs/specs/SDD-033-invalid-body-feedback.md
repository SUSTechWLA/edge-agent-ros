# SDD-033 机体反馈失效时撤销观测与控制依据

## 背景和价值

校园飞行器按目标高度与最新机体高度的误差发送垂向速度，Go1 和 G1 依靠 IMU 与关节编码器验收动作。驱动刚上线、定位丢失或测量溢出时，消息可能带有 NaN、无穷大或不完整的关节数组。旧适配器直接缓存位姿，一台机体的异常值会使严格 JSON 遥测无法序列化。对无效高度限幅还可能产生上升指令。无效 IMU 或编码器帧也可能让上一帧继续用于控制，直到三秒后超时。

## 改动与边界

由校园机体适配器在三个输入回调的缓存边界处理异常。失效只撤下相应机体的相应观测，保留其余机体和传感器的证据。缺少飞行高度时沿用已有零速度请求和有界等待，持续失联时产生带 operation ID 的失败回执。已有 SQLite 回执保持可重放。消息结构、ROS 话题、外部插件权限和控制限幅沿用现有契约。真实飞控在定位丢失时的独立保护需按机型验收；该适配器运行于仿真。

## 验收

| 编号 | 注入与期望 |
|---|---|
| AC-1 | 已接受起飞后给 Crazyflie 一帧非有限高度。下一次控制 tick 发垂向零速度；遥测保持有效 JSON，其他机体位姿保留。持续失效后重投原操作仍返回同一受阻结果。 |
| AC-2 | 给四足编码器一帧缺项、重复必需关节或非有限角，或给 G1 IMU 一帧非有限加速度。在三秒新鲜窗口内立即拒绝以旧观测接受新操作。 |
| AC-3 | 恢复有效观测后重新具备准入条件；零长度或非有限机体四元数无法成为可用位姿。既有正常动作与跨机体隔离测试继续通过。 |
| AC-4 | 一次新的受控飞行动作启动后给提供者 SIGTERM。独立 ROS 订阅者应在退出前接到新的零速指令，进程正常退出。SIGKILL 及断电的执行器看门狗须另行验证。 |

## 变更记录

2026-11-18 按现场预部署回归登记。基线镜像为 `edge-agent-ros:tu-delft-x`，修复前后使用同一故障注入测试。退出本变更时可换回上次镜像并停止依赖异常反馈的动作。

第二轮在真实 Gazebo Transport、ROS 2 与 HTTP 进程边界重放异常时，退出日志出现 `publisher's context is invalid`。默认 ROS 信号处理先销毁上下文，清理阶段的最后一条零速发布失败。登记 AC-4，要求提供者持有正常停止次序。
