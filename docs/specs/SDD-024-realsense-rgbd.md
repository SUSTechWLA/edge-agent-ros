# SDD-024 · 对齐深度图与 RealSense D4xx 像素测量

## 背景与价值

相机预览可看到 RGB 内容，三维雷达可测表面，却无法回答“我在彩色图中点的这一像素有多深”。D435i/D455 或仿真 RGB-D 相机可提供配准到彩色光学坐标的深度图。单看图像同尺寸无法证明光轴、采样时刻和几何校准一致。

## 设计与契约

独立只读 rgbd 服务消费 ROS 2 sensor_msgs/Image 彩色、来源明确的已对齐深度，以及 sensor_msgs/CameraInfo。每个进程对接一台相机。安装配置声明深度已由一体化仿真相机或厂商的 align_depth 产生。核验三个 frame_id、分辨率、有效内参、相同时钟域和最大 20 ms 的采样差，缓存有界。公开 HTTP 保留三个话题、时间戳、坐标、校准信息和配准声明来源。元数据能识别误接，校准的物理正确性仍需独立标定和实物标尺验证。

端口 8772。GET /health 用启动事件确认实例，/api/rgbd 给出状态与有效帧对身份。/frame/color.png 和 /frame/depth.png 可按 pair 查询，后者为标尺明确的伪彩预览。/api/sample 用原始图像 u,v 和帧对身份返回该像素 RGB 和沿光轴的深度（米）。16UC1 的毫米值和 32FC1 的米值在原始存储地址解码，支持行末填充、大小端、零和非有限值。旧帧、坏像素和无配准证据返回可区分错误。浏览器点击显示度量；按帧身份取样保证光标和数值属于同一画面。软件只持有内存中的短时帧，启动、失配、恢复、过期和重置写入独立 ModuleJournal。

## 验收与证据

- AC-1 彩深预览与原始像素独立对照，覆盖两种单位、字节序、步长、越界、零、NaN、无穷、截断以及预览缩放。
- AC-2 非同帧、过大时间差、退化 CameraInfo、尺寸不等、时钟回退和断流触发可查询错误。校准恢复后重建帧对。未确认配准时不能对 RGB 像素给出深度。
- AC-3 独立 Docker 中安装和停止 RGB-D 服务，原相机、地图和 Agent 可继续运行。通过独立 ROS/Gazebo 源验证页面、像素查询及来源归属。RealSense 驱动输出由标准 ROS 等价消息验证，真 USB 与距离误差另作实机验收。

## 迁移与回退

仿真 Compose 附加 compose.rgbd.yaml；真机另加 compose.rgbd-hardware.yaml，外部已标定驱动持有 USB。按部署情况替换声明文件与实际命名空间，重建单个 rgbd 容器即可应用；停止 rgbd 只关闭此次测距。D4xx 的标准彩色流和驱动点云可分别登记到既有 camera / map3d 服务。
