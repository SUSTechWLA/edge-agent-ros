# SDD-026 按地图类型观察二维栅格与三维空间

## 背景与价值

在基线 `6aeb6be`，工作台可观察二维地图，选装地图页面可观察点云。点云页面的“俯视”仍使用同一个三维投影，不能查询某个占据单元，旋转后也难以读出实测点的位置。开发者需要借二维回答“这一格的占据值是多少”，借三维回答“这个回波来自哪个位置与高度”。本次支持二维和三维，沿用当前地图插件、ROS 观测与已有工作台入口。

## 设计与契约

`perception/map3d` 持有只读快照。`GET /api/map` 保留原有字段，增加可选二维栅格，包括 ROS 源话题、坐标系、米制分辨率、原点 XY 与偏航、行主序格值、采样时刻与状态。仅叠加同坐标系的有效几何；数据缺失时明确标识投影或等待。拒绝过大、姿态不适用或非法的栅格；时钟回退清除旧数据，沿用插件事件留痕。地图输入与用户浏览均没有控制机器人或写入地图的权限。

浏览器共享只读快照、来源过滤、显示状态和按需重绘。二维与三维各自拥有画布、相机、拾取语义、拖动手势和视角复位。二维使用固定 XY 米制投影；三维使用透视相机、环绕目标、平移与距离缩放。用户可通过键盘和触摸交互。切换可保留每种视图的观察位置；跨坐标系或时钟代际清除过期选择。离线部署使用插件自带的资源。

## 验收与证据

二维和三维共同消费同一栅格与同一组语义区域、物体。两种视图复用原点旋转、格子索引、格值解释与色带。三维把栅格置于 ROS 原点所在的水平面；物体的高度来自有尺寸的先验或三维传感器。一个 XY 单元只记录一个占据值，多层通行空间需要独立三维几何。

### 后续纹理接入

地面正射影像可以作为独立外观图层，按地图 frame、物理范围、米/像素与朝向，以相同的世界坐标定位。标明图像来源、采集时刻／版本、实拍或合成属性；纹理关闭、缺失或过期时仍能读取原始格值和语义。立面纹理需要已知的墙面几何与 UV 或相机内外参；一张俯视栅格无法提供立面朝向与遮挡关系。运动规划继续消费有版本的占据和语义证据。两种视图本轮仅绘制已有证据图层。

| 编号 | 用户行为或故障 | 验收判据 |
|---|---|---|
| AC-1 | 打开二维，拖动、缩放、点击单元 | 平面方向固定，屏幕像素可对照真实 ROS 格值、原点和分辨率，未知值单独表达。缺少栅格时可检查已知先验或 XY 点云投影。 |
| AC-2 | 打开三维，环绕、平移、缩放、俯视、拾取 | 几何随透视相机更新，选中可见元素得到带单位的世界坐标或来源，保留原有点云来源选择、图层和诊断。 |
| AC-3 | 反复切换地图、改变画布尺寸或触摸操作 | 两种模式使用各自手势，仅激活一个画布；恢复各自视角，控件、拾取与空数据状态匹配当前视图，窄屏无横向溢出。 |
| AC-4 | 无栅格、错帧、畸形、过期或时钟回退 | 客户端可以识别数据状态，旧代际数据清除；三维观测仍可使用；ROS/API、浏览器和既有消费者分别回归。 |

## 迁移与回退

发布时仅重新部署选装 `map3d` 服务；运行中的浏览器刷新取得配套脚本。原始 Console 平面图与旧快照消费者保持兼容。回退可重新部署升级前的地图镜像，继续使用现有端口、配置、只读观测和回执；地图插件重启后利用新采样重建内存观测。
