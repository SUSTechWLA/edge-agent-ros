# SDD-048 从实时探索到离线查看累计地图

## 背景与价值

一辆刚进入陌生楼道的车可以发布雷达建立的占据栅格。车顶可能有相机，楼道通常没有俯视相机。开发者想看见第一次回波标出了什么，转弯后新增了哪里，重走走廊时又修正了哪些障碍。SDD-046 能同步播放图像、传感器和任务事件，原有地图镜头居中裁取最近一帧。地图窗口平移、定位重置或外部相机缺席时，仅靠这幅镜头很难解释探索成果。本次在可选录制插件加入累计地图视图，Gazebo 和板端共享同一份观测契约。

## 设计与契约

| 责任 | 输入 | 操作与输出 |
|---|---|---|
| 物理采集者（沿用部署授权） | ROS `OccupancyGrid`、可选车载相机；模拟环境可再指定外部视角 | 保存格值、尺寸、二维原点、分辨率、地图坐标系、源时间和可取得的发布者/地图世代。车载与俯视有独立角色、限频和媒体路径。相机完全缺席也能录制。 |
| 录制器（既有软服务） | 每次任务单独的时间线、不可变媒体及摘要 | 接收数据的顺序决定何时可见。两个只读入口 `GET /recordings/{id}/global-map` 和 `GET /recordings/{id}/map-view` 查看已经收到的观测。录制开关、任务终态、设备租约与原操作所有者沿用原契约。 |
| 地图累计与分段（插件内部纯函数与状态） | 当前录制或人工确认的地图身份、标准二维栅格 | 首次观测前全图未知。原点沿同一栅格平移时扩展范围；已测单元更新，未知单元保留原证据。分别统计首次发现与已有格变化。帧、发布者、时钟或栅格几何失去可比性时保留旧段；需要重新确定位置的段独立显示。 |
| 离线演示与归档 | 相同的时间线、已封存栅格和可选媒体 | 导出能独立播放的视频、按时间拖动的整图和可重新打开的地图。首次播放只显示到该时刻已经收到的信息；已存的整图有来源、身份、坐标系、分辨率与摘要。 |
| 历史图加载 | 用户指定的不可变地图目录及校验清单 | 查看历史地图不需要 ROS、设备或摄像头。尝试与新观测合并还需同一地点、坐标基准、世代与几何证据；同名 `odom` 不足以建立跨任务对齐。 |

同一格的新鲜观测可以将原有障碍改成空闲，`-1` 仅表示此帧没有测得。覆盖范围以已知格数、米制面积和当前图框定义；缺少场地总面积时不显示“完成勘察整座校园”的百分比。仿真世界几何与世界位姿可以供独立验收使用。产品地图只消费实测占据栅格。旧录制中的二维原点无法事后重建原始倾角，缺少身份的图只能说明该段录制观察到了什么。

资源边界沿用既有地图存档限制。在线读取按任务分页消费已附摘要的地图事件，有界缓存按需重放。损坏附件、时钟冲突、容量越界、源暂停和服务重启均应留下可解释的状态，独立于任务判定。地图服务没有控制入口。录制默认关闭。

## 验收与证据

| 编号 | 正例 | 反例及故障注入 | 证据入口 |
|---|---|---|---|
| AC-1 合并与因果 | 从零开始，合法平移、格值修正、负坐标和部分重叠，测量首见及更新数 | 未知不清除合法已知格；时戳冲突、坐标不匹配、全未知复位、图幅超限不得把错图拼起来 | 纯栅格与跨段 UT、源序列和地图清单 |
| AC-2 可选相机 | 有双视角、只有车载、无相机三种配置；离线与现场可读 | 实机选择 Gazebo 视角应拒绝；缺相机既不阻塞地图，也不虚构图像 | 采集器与入口 UT、仿真输入及来源计数 |
| AC-3 进行中的地图 | 向正在录制的任务提交两个平移窗口，在 HTTP 查看两次实际增长 | 零样本、错任务、损坏附件、客户端重连、不可对齐的新段；变更观察不触发动作 | HTTP 黑盒与原始事件序号 |
| AC-4 离线与历史 | 时间轴能回到未知，视频、网页最终栅格与重新加载的独立地图一致 | 摘要篡改、时序倒放、不同站点底图、源信息缺失；旧归档可读 | 离线地图、浏览器交互、完整视频解码、重载比对 |
| AC-5 工程与现场边界 | 在真实 Gazebo 校园流程运行故障/恢复/返航，另跑无成像传感器的场景；生成发布投影 | 保留原始失败样本及旧验收。无世界真值输入的制图与独立验收分开核对 | 试验记录、发布清单及板端待验说明 |

## 迁移与回退

录制器继续接受原归档与原启动选项。默认录像布局和软件任务证据继续可用。升级时先完成或封存原录制，选用新版本的地图视图。回退时切回 SDD-046 的插件和部署镜像；封存的原采样仍可由旧工具重放。存档是观测成果，导航上线仍需现场定位、标定与独立验收。

## 变更记录

本阶段先固定数据、时间和坐标的契约，再在录制插件、采集适配器及其直接验收入口实现。板端实车、未知大范围地图的漂移与闭环精度须单独实测。
