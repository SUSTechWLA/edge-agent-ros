# SDD-040 用工厂已测量靶点求解传感器安装外参

## 背景与价值

同型号无人车的雷达和相机也会有安装偏差。仅凭传感器在线和静止的重力方向，无法求得安装位置与全部朝向。工厂可以复用一套已在底盘坐标系中测量的靶点，使每台车从成对观测得到自己的外参，并留下可复核的误差。

## 设计与契约

工装适配器交付指定传感器坐标系与底盘坐标系中的同名三维点，单位为米。工厂固定安装方案提供帧、机体、设备序列号和工装编号。用拟合组计算使平方残差最小的刚体旋转和平移，强制旋转矩阵行列式为正；用未参与拟合的另一组靶点检验结果。输出的变换方向始终为传感器点到车体系，即 TF 的父为车体、子为传感器。求解工具生成候选，工厂标定插件负责按本车配置验收和发布。静止 IMU 的三维安装应由工装、安装测量或专用运动激励提供。

## 验收与证据

- AC-1 可复现带旋转与平移的已知输入，报告每组点数、RMS、最大误差、方向、frame 与原始输入哈希。
- AC-2 输入为空、非有限、单位错误、空间分布太窄或接近共线、点位重复、验证组复用拟合点及验证超差时不输出可采用的变换。
- AC-3 真实设备没有测量输入时，程序明确列出所缺信息。仿真输入与工厂记录分开保存。

## 迁移与回退

新功能单独随标定插件交付。候选仅供验收，不直接覆盖 TF、运动配置或上一版已发布标定。删除本次任务的未采用候选不会改变机器人已有配置。
