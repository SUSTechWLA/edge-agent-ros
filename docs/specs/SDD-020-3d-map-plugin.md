# SDD-020 · 可独立启停的三维地图

## 背景与价值

基线 735fee3 中地图卡片消费平面栅格、水平 LaserScan、位姿及场地先验。已有场景文件保存物体实际设计高度和屋顶离地高度。轮式车看到墙面上的一个平面截线，无法判断头顶净空。开发者需要查看不同高度的实际回波，同已知场地交叉检查；新传感器不应改变导航的输入或权限。

## 设计与契约

观测台为独立感知页面提供一个声明式入口。受信部署清单给出视图 ID、同主机端口、显示名称及所在卡片。页面定期从部署目录读取清单，检查插件的启动事件是否属于当前 Console 归档，再显示链接。增加其他传感器页面只需登记视图和公开相同健康契约。目录移除、插件退出或归档不匹配时撤下对应入口。

独立地图进程消费标准 ROS 2 PointCloud2，按采样时刻将有限数量的 XYZ 点转换到配置的固定坐标系，维护有容量上限的体素表。HTTP GET /api/map 公开版本、坐标系、来源话题/坐标系、采样时间、单元尺寸、已观测点和状态。此结果可被前端与将来的感知插件复用。地图服务也订阅既有语义地图与融合位姿，分别显示先验和机器人；任一层离线只影响本层。空白、过期、输入异常都要可辨认。地图表示命中过的表面，未知空间没有安全通行含义。

浏览器独立查看器支持旋转、缩放、俯视、图层和复位。可选 Gazebo 传感器在场景内动态安装固定多线雷达，桥接原始点云并发布已知静态外参。固定站坐标与模型 pose 对齐是仿真配置，实际机载雷达由机器人提供时间对应的 ROS TF。现有控制内核、融合、任务、动作与 2D 栅格接口沿用。控制台地图入口只负责导航。独立地图服务没有设备或任务提交接口。

## 验收与证据

- AC-1 对照独立 XYZ 输入，验证跨高度、变换、去重、容量、非法点、异常布局、时钟回退和迟到数据。标出来源，失去定位不把传感器本地坐标冒充地图坐标。
- AC-2 在活动 Gazebo 中热启传感器和地图，实测点云有多个不同 z。停止传感器后图层显示过期，旧的二维导航链仍工作。重新启动可恢复。
- AC-3 浏览器展示实测点、带独立来源的先验与位姿，能切换、旋转、缩放及复位。空源和连接中断有明确提示。独立服务退出不改变原有任务与地图。
- AC-4 两个 Compose 均提供地图，实机使用已有驱动；输出受限。源健康、版本、时钟世代变化可追查。实机标定和部署单列待实测。

## 迁移与回退

使用 map3d profile 部署地图，map3d-sensor 提供仿真桥。停止选装桥会撤下 ROS 点云与 TF。Gazebo 世界保有单个台站，再次接入时复用。短期地图由新进程从新观测重建。
