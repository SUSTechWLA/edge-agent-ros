# 模块三 · ROS 执行网关

`edge_gateway` 在独立进程实现 `/edge/navigate_to`。机器人适配器以 `/odom` 为位置反馈、用 `/cmd_vel` 发速度指令。默认仿真的室内外轮式底盘开启前向激光停车检查。具名地点间的可通行路线由场景提供者计算；网关沿每一个给定目标行驶。真机部署需要对应机体的执行器和制动验收。

每周期用目标减当前位置计算距离和期望航向，先控制航向，再按距离限制线速度；限制线速度和角速度。进入目标容差后持续发布零速并核实接连收到的低速里程计样本，才返回 reached 和实测坐标。反馈上报剩余距离。

新目标要求操作 ID 非空、点合法、数据健康、控制资源空闲。接收时保留资源；检查操作心跳、里程计单调到达时间、动作总时限和取消请求。安全分支先下发零速，能证明停稳才允许正常取消/交接；观测缺失需给出结果未知或明确的失败，由内核阻断后续动作。真机的最后一道失联保护须在底盘控制器独立实现。本版仅作为仿真适配器。

## 实现参数与复核入口

网关每 50 ms 运行一次，线速度上限 0.32 m/s，角速度上限 1.1 rad/s。目标距离 ≤0.055 m 时申请停车。至少三个新的里程计样本满足线速度 <0.025 m/s、角速度绝对值 <0.05 rad/s，并在采集时间和本机接收时间上均连续覆盖至少 300 ms，才可确认停稳。发生速度回升或样本间隙超过 200 ms 会重新计时。此条件来自一次取消任务的[独立真值记录](../../artifacts/verification/20261117-031103-3a9cc1/cancel.json)，当时连续三帧低轮速之后仍观察到车体短暂回弹。超过 0.9 s 未收到有效里程计或 1.5 s 未收到对应操作的心跳会撤销运动。停车后 3 s 仍无证据，返回带 `UNKNOWN:` 的结果并禁止新动作。所有门限适用于本版仿真。

实现见[网关节点](../../src/edge_gateway/src/edge_gateway_node.cpp)。[网关探针](../../src/edge_gateway/test/watchdogs.py) 会刻意在取消之后继续反馈移动，以检查收到取消回执时任务仍在等待停稳。

### 激光、时钟与故障归因

本仿真雷达为 360 束，网关检查航向正前方 ±0.42 rad。开启 `require_scan` 后，正前方单束近障已足以触发前进制动。判断能否看清前方时，还要检查整个扇区内相邻有效束之间、扇区边界与最近有效束之间的角度间隙。允许的最大间隙为 0.12 rad（约 6.9°）。此值针对默认模拟底盘，更换雷达、车宽、速度或控制器后需要重新标定。有效角度与量程以 `LaserScan` 元数据为准。+Inf 表示量程内无回波，−Inf 表示过近，NaN 表示读数未知，超出声明量程的有限数值不参与判断。[ROS REP-117](https://github.com/ros-infrastructure/rep/blob/master/rep-0117.rst)

| 注入条件 | 网关记录 | 如何判断结果 |
|---|---|---|
| 正前方缺测、角度几何错误，或前方有限读数均超量程 | `navigation.scan_invalid` | 在场景继续推送新帧时也制动。默认仿真注入 ±0.23 rad 缺测，同时观察速度命令与独立 Gazebo 世界位姿。 |
| 前进方向任一可信束报告距离小于 0.42 m 或 −Inf | `navigation.path_blocked` | 已知近障立即触发停车；其他束缺测也保留近障原因。 |
| 按墙钟持续送新帧，但激光与里程计的采集时间差大于 1 s | `navigation.scan_time_mismatch` | 核对两个传感器的时钟域，修复后用新动作对已停稳的底盘复测。 |
| 持续重发同一时间戳、断流或只发送错误坐标系的激光 | `navigation.scan_stale` | 最后有效扫描超过 1 s，撤销运动。 |
| 仿真中途时钟回拨，之后的里程计持续早于已使用样本 | `navigation.odom_timeout` 开始制动；停稳无法核实则 `navigation.stop_unconfirmed` | 保留未知结果和底盘占用。需核对现场、原动作和实例生命周期后恢复；单独重启传感器不能为旧动作提供同一时间线的停车证据。 |

复测使用[运动故障探针](../../tests/system/motion_faults.py)。无 Gazebo 模式运行真实 ROS 网关并注入传感器样本。Gazebo 模式把私有测试网关的扫描输入重映射至 `/motion_test/scan`，由探针转发真实 `/scan` 并切换缺测，另从 `/ground_truth` 量取制动后余行。停止命令的响应时间与物理位移分别记录。
