# 模块三 · ROS 执行网关

`edge_gateway` 在独立进程实现 `/edge/navigate_to`。机器人适配器以 `/odom` 为位置反馈、用 `/cmd_vel` 发速度指令。支持平坦无障碍试验场。任务内核不持有速度发布器。

每周期用目标减当前位置计算距离和期望航向，先控制航向，再按距离限制线速度；限制线速度和角速度。进入目标容差后持续发布零速并核实接连收到的低速里程计样本，才返回 reached 和实测坐标。反馈上报剩余距离。

新目标要求操作 ID 非空、点合法、数据健康、控制资源空闲。接收时保留资源；检查操作心跳、里程计单调到达时间、动作总时限和取消请求。安全分支先下发零速，能证明停稳才允许正常取消/交接；观测缺失需给出结果未知或明确的失败，由内核阻断后续动作。真机的最后一道失联保护须在底盘控制器独立实现。本版仅作为仿真适配器。

## 实现参数与复核入口

网关每 50 ms 运行一次，线速度上限 0.32 m/s，角速度上限 1.1 rad/s。目标距离 ≤0.055 m 时申请停车。至少三个新的里程计样本满足线速度 <0.025 m/s、角速度绝对值 <0.05 rad/s，并在采集时间和本机接收时间上均连续覆盖至少 300 ms，才可确认停稳。发生速度回升或样本间隙超过 200 ms 会重新计时。此条件来自一次取消任务的[独立真值记录](../../artifacts/verification/20261117-031103-3a9cc1/cancel.json)，当时连续三帧低轮速之后仍观察到车体短暂回弹。超过 0.9 s 未收到有效里程计或 1.5 s 未收到对应操作的心跳会撤销运动。停车后 3 s 仍无证据，返回带 `UNKNOWN:` 的结果并禁止新动作。所有门限适用于本版仿真。

实现见[网关节点](../../src/edge_gateway/src/edge_gateway_node.cpp)。[网关探针](../../src/edge_gateway/test/watchdogs.py) 会刻意在取消之后继续反馈移动，以检查收到取消回执时任务仍在等待停稳。
