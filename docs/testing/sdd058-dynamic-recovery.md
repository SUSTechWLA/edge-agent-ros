# 已归档的 SDD-058 动态通道复查仿真验收

两套独立 Gazebo 站点加载同一份已发布 Swarm 地图。地图 ID 为 `sdd058-autonomy-02`，摘要为 `40365da45044cfdc2c57946c71829affd3e00b5b0e97fc8654fcbb79c73a25f9`。两次任务均由实际浏览器输入并提交「前往Swarm会议室」，各只有一次任务提交。两套站点均使用 0.55 米扫掠净距和原轮廓、速度、制动参数。

## 复查和恢复

Gateway 依据连续有效扫描、停稳里程计、可见扫掠区、原冲突带和后续目标判断能否释放动态保持。若待跟踪目标换用 ID 或从观测消失，需要 8 组以上连续观测，在扫描和里程计两端均覆盖至少 875 毫秒。身份或观测中断会重置连续计数。若下层以防撞原因结束路段，Agent 使用新的同步激光、定位和动态轨迹，在基础地图版本和外层操作号冻结的条件下调用 `planning.corridor_review`。独立碰撞保护仍由 Gateway 执行。

复查服务只接收数据和有限长度的区段，输出等待或带证据的净空结论。Agent 的任务会话核对原操作的停稳回执、同一个 Gateway 实例和相同地图摘要。先前路段停止后，路线提供者若选出不同局部区段，Agent 先复查新目标再派发。复查服务离线、采样过期或持续看不见净空时保持停车。预算用尽后记录阻塞和停止事实。

任务台的绿色规划参考线保留当前局部目标与最终停靠位。路线插件在冻结的发布地图和规划时的实时占用观测上检查捷径与转角曲线的净空，空间不足时缩小转角过渡或保留原拐点。青色虚线直接显示实测里程计轨迹。此显示更新在下列录像完成后加入。
